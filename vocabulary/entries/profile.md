# profile

- **音标**：/ˈprəʊfaɪl/（BrE）; /ˈproʊfaɪl/（AmE）
- **词性**：n. / v.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁 / 意大利语 pro-（向前）+ filum（线条）→ 侧面轮廓线
- 构词提示：先指脸的侧面轮廓，后引申为“个人资料 / 人物简介”；  
  易混：**profit**（利润）读音/拼写相近，但意思和词源都不同

## 2. 高频常用意思

1. **个人资料；档案**（n.）— a short description of a person, company, or account info
2. **侧面；侧影**（n.）— the outline of a face seen from the side
3. **概述；简介**（n. / v.）— a summary；to describe briefly

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| user profile | 用户资料 |
| create a profile | 创建个人资料 |
| company profile | 公司简介 |
| keep a low profile | 保持低调 |
| high-profile | 高调的；备受关注的 |
| customer profile | 客户画像 |

## 4. 常用句子

### 句子 1
> Please update your profile with a new photo.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Please | 请 |
| update | 更新 |
| your | 你的 |
| profile | 个人资料 |
| with | 用 |
| a | 一张 |
| new | 新的 |
| photo | 照片 |

**语法拆解**
- 句型：祈使句
- 主干：(You) + update + your profile
- 时态 / 语态：祈使语气
- 其他成分：with a new photo 表方式/内容

### 句子 2
> She keeps a low profile on social media.

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| keeps | 保持 |
| a | 一种 |
| low | 低的 |
| profile | 姿态 / 曝光度 |
| on | 在 |
| social media | 社交媒体 |

**语法拆解**
- 句型：主谓宾 + 地点状语
- 主干：She + keeps + a low profile
- 时态 / 语态：一般现在时（习惯）
- 其他成分：on social media 表场景
