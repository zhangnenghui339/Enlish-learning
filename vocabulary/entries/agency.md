# agency

- **音标**：/ˈeɪdʒənsi/
- **词性**：n.
- **首次日期**：2026-09-14
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **能动性；主体性**（n.，哲学 / 心理 / AI）
   - 中文：能自己起意、自己动手、把事情做成的那种「我能做事」
   - 英文解释：the capacity to act as an agent — to choose, to start something, to make the world move because *you* did it, not because you were only pushed
2. **代理机构；中介公司**（n.）
   - 中文：替别人办事的公司（广告公司、旅行社、人才中介）
   - 英文解释：a business that acts for someone else — it does the doing on a client’s behalf
3. **代理权；作用；促成**（n.）
   - 中文：被授权去行动；或「靠某种力量才发生」
   - 英文解释：the authority to act for another; also “by the agency of” = through the working of some force or person

## 2. 原子意思

- **原子**：拉丁 *agere* = **做、驱、把事情推着走**；*agent* = 那个在做的人；**agency** = **「能做」这件事本身**（能力、身份、或替人做的那摊）
- **英文取词**：描述动作 —— **有一只手在推**：自己推、替人推、被授权去推
- **中文取词**：谈人能不能做主叫**能动性**，谈替人办事的公司叫**代理**，谈合法去做叫**代理权**
- **所以不是一词多义**：同一个「在做、能做」；中文才按对象拆成不同词

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **a sense of agency** | 感觉是「我在推」，不是世界推我 | **主体感 / 能动感** |
| **moral agency** | 能负责地去做、能被问责 | **道德主体性** |
| **an ad agency** | 一摊专门替客户去做广告的人 | **广告代理公司** |
| **by the agency of fire** | 火在「做」这件事 | 中文改口说**凭借 / 通过……的作用** |

相关词：**agent**（行动者；代理人）、**act / action**（做；行动）。

## 3. 词根

- 词根 / 词缀：**ag- / act-** ← 拉丁 *agere / actus*（做、驱）+ **-ency**（状态 / 性质）
- 真同源：
  - **agent** — 行动者；代理人
  - **act / action / active** — 做；行动；主动的
  - **agenda** — 要去做的事清单
  - **agile** — 做得动、转得快
  - **exact** — 逼着做出来 → 精确的；强求
  - **transaction** — 做过去、做过来 → 交易
- 形近勿混：
  - **age** — 年龄，来自拉丁 *aetas*，**不是** agere
  - **agony** — 极度痛苦，来自希腊 *agon*（竞赛），不是「做」
  - **agency** 的「公司」义和「能动性」义是同一原子，别当成两个无关单词
- 构词提示：看见 **ag- / act-** 先问「是不是在做、在推」；**age / agony** 对不上就别硬捆

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| sense of agency | 主体感（觉得是我在行动） |
| human / moral agency | 人的能动性 / 道德主体性 |
| lose / restore agency | 失去 / 恢复能动性 |
| ad / travel / talent agency | 广告 / 旅行 / 经纪公司 |
| agency simulation | 能动性模拟 |
| an agent | 行动者；代理人 |

## 5. 常用句子

### 句子 1
> Therapy helped her recover a sense of agency.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Therapy | 心理治疗 |
| helped her | 帮助她 |
| recover | 恢复 |
| a sense of agency | 一种「我能做事」的感觉 |

**语法拆解**
- 句型：主语 + help + 宾语 + 不带 to 的不定式
- 主干：Therapy + helped + her + recover…
- 时态 / 语态：一般过去时
- 其他成分：a sense of agency 是 recover 的宾语——找回「手在自己这边」

### 句子 2
> The model shows language skill, not true agency.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The model | 这个模型 |
| shows | 表现出 |
| language skill | 语言技能 |
| not | 而不是 |
| true agency | 真正的能动性 |

**语法拆解**
- 句型：主谓宾 + 否定对照
- 主干：The model + shows + language skill
- 时态 / 语态：一般现在时
- 其他成分：not true agency 把「会说」和「能自己起意去做」拆开

### 句子 3
> She hired an agency to run the campaign.

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| hired | 雇了 |
| an agency | 一家代理公司 |
| to run the campaign | 来运作这次活动 |

**语法拆解**
- 句型：主谓宾 + to 目的状语
- 主干：She + hired + an agency
- 时态 / 语态：一般过去时
- 其他成分：这里 agency 是「替人做」的公司，不是哲学里的能动性
