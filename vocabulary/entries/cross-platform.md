# cross-platform

- **音标**：/ˌkrɒs ˈplætfɔːrm/
- **词性**：adj. / n. modifier
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：cross-（跨越）+ platform（平台）
- 构词提示：跨过多个平台的；**cross-platform gap** = 跨平台能力上的空白  
  对比：unified dashboard = 统一看板（常是 cross-platform 的解决方案形态）

## 2. 高频常用意思

1. **跨平台的**（adj.）— working across multiple platforms or systems
2. **跨平台（能力/视图）**（n. 语境）— a cross-platform view of opportunities

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| cross-platform gap | 跨平台空白 |
| cross-platform view | 跨平台视图 |
| cross-platform solution | 跨平台解决方案 |
| cross-platform monitoring | 跨平台监控 |

## 4. 常用句子

### 句子 1
> The cross-platform gap is acknowledged, but no affordable solution fills it.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The cross-platform gap | 跨平台空白 |
| is acknowledged | 被承认 |
| but | 但是 |
| no affordable solution | 没有可负担的方案 |
| fills it | 填补它 |

**语法拆解**
- 句型：并列转折句
- 主干：gap is acknowledged / no solution fills it
- 时态 / 语态：一般现在时；前半被动
- 其他成分：it 指代 the cross-platform gap
