# utility

- **音标**：/juːˈtɪləti/
- **词性**：n.（偶作 adj.）
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **实用工具；小工具**（n.，软件/产品）— a small, focused tool that does one useful job well（如 compressor、prompt cleaner）
2. **效用；实用性；有用性**（n.，抽象）— how useful something is；usefulness
3. **公用事业**（n.，常 pl. utilities）— 水电煤气等公共服务公司/服务
4. **实用的**（adj.，较少）— designed for practical use rather than beauty（如 utility knife 美工刀/多用刀）

## 2. 词根

- 词根 / 词缀：
  - **util-** ← 拉丁 *utilis*（有用的）← *uti*（使用）
  - **-ity** — 名词后缀（性质/状态）
- 同源词：
  - **useful** — 有用的
  - **utilize / utilise** — 利用
  - **utilization** — 利用；使用率
  - **utilitarian** — 功利的；实用主义的
- 构词提示：核心是「**有用**」——可以指「有多有用」（抽象），也可以指「那个有用的小东西」（工具），美式口语里 utilities 还专指水电账单那一类服务

## 4. 常用句子

### 句子 1
> Compress and Prompt Cleaner are small utilities in the workflow.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Compress and Prompt Cleaner | 压缩工具和提示词清理器 |
| are | 是 |
| small utilities | 小实用工具 |
| in the workflow | 在工作流里 |

**语法拆解**
- 句型：主系表 + 地点状语
- 主干：Compress and Prompt Cleaner + are + utilities
- 时态 / 语态：一般现在时
- 其他成分：small 定语；in the workflow 表范围

### 句子 2
> The feature has high utility but a dull interface.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The feature | 这个功能 |
| has | 有 |
| high utility | 很高的实用性 |
| but | 但是 |
| a dull interface | 乏味的界面 |

**语法拆解**
- 句型：主谓宾 + but 转折
- 主干：feature + has + utility
- 时态 / 语态：一般现在时
- 其他成分：high 修饰 utility；but … 对比外观

### 句子 3
> Utilities went up again this month.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Utilities | 水电煤等费用/服务 |
| went up | 上涨了 |
| again | 又 |
| this month | 这个月 |

**语法拆解**
- 句型：主谓 + 时间状语
- 主干：Utilities + went up
- 时态 / 语态：一般过去时
- 其他成分：again / this month 表时间与重复
