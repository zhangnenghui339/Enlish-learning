# brand-new

- **音标**：/ˌbrænd ˈnjuː/（BrE）; /ˌbrænd ˈnuː/（AmE）
- **词性**：adj.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：brand（烙印、品牌）+ new（新的）
- 构词提示：旧时货物出厂会打 brand（烙印）表示全新未用 → **brand-new** = 崭新的、全新的  
  写作：常作 *brand-new*（有连字符）或 *brand new*

## 2. 高频常用意思

1. **崭新的；全新的**（adj.）— completely new; never used before
2. **（状态）像刚出厂一样新**（adj.）— not second-hand or worn

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| brand-new phone / car | 全新手机 / 车 |
| brand new day | 崭新的一天；新的开始 |
| feel brand-new | 感觉焕然一新 |
| brand-new start | 全新开始 |

## 4. 常用句子

### 句子 1
> She bought a brand-new laptop yesterday.

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| bought | 买了 |
| a | 一台 |
| brand-new | 全新的 |
| laptop | 笔记本电脑 |
| yesterday | 昨天 |

**语法拆解**
- 句型：主谓宾 + 时间状语
- 主干：She + bought + a brand-new laptop
- 时态 / 语态：一般过去时
- 其他成分：brand-new 作前置定语

### 句子 2
> After the reboot, the app felt brand-new.

**逐词翻译**

| 词 | 意思 |
|----|------|
| After | 在……之后 |
| the reboot | 重启 |
| the app | 这个应用 |
| felt | 感觉起来 |
| brand-new | 全新的 |

**语法拆解**
- 句型：时间状语 + 主系表
- 主干：the app + felt + brand-new
- 时态 / 语态：一般过去时
- 其他成分：After the reboot 表时间
