# influencers

- **音标**：/ˈɪnfluənsərz/
- **词性**：n. pl.（单数 influencer）
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **网红 / 意见领袖**（n.）— people with a large online following who can shape others' opinions or buying
2. **有影响力的人**（n.）— someone who affects what others think or do（不一定是网红）
3. **influencer marketing**（相关）— 找达人带货/种草的营销方式

## 2. 词根

- 词根 / 词缀：
  - **influence** = **in-**（进入）+ **flu-**（流，同 fluid）→ 影响力「流入」他人想法
  - **influencer** = influence + **-er**（做……的人）
  - **influencers** = 复数 -s
- 构词提示：能把态度/购买欲「流」进粉丝脑子里的人 → 影响者 / 网红

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| social media influencers | 社交媒体网红 |
| influencer marketing | 达人营销；网红营销 |
| micro-influencer | 腰部/小众达人（粉丝不算巨大） |
| brand influencer | 品牌合作达人 |
| work with influencers | 与达人合作 |

## 4. 常用句子

### 句子 1
> Brands hire influencers to promote new products.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Brands | 品牌方 |
| hire | 聘请 |
| influencers | 网红 / 达人 |
| to promote | 来推广 |
| new products | 新产品 |

**语法拆解**
- 句型：主谓宾 + to 不定式表目的
- 主干：Brands + hire + influencers
- 时态 / 语态：一般现在时
- 其他成分：to promote new products 表目的

### 句子 2
> Influencers are a key part of Creator Data Infrastructure.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Influencers | 网红 / 达人 |
| are | 是 |
| a key part | 关键部分 |
| of | ……的 |
| Creator Data Infrastructure | 创作者数据基础设施 |

**语法拆解**
- 句型：主系表
- 主干：Influencers + are + a key part
- 时态 / 语态：一般现在时
- 其他成分：of Creator Data Infrastructure 限定 part
