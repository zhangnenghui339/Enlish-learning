# Context Splitter

- **音标**：/ˈkɒntekst ˈsplɪtə/
- **词性**：n. phrase（产品功能名）
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **上下文拆分器**（n.）— a tool that splits long context into smaller chunks for an AI model
2. **context** — 上下文；语境；（给模型的）背景材料
3. **splitter** — 拆分器；分割工具

## 2. 词根

- 词根 / 词缀：
  - **context** ← 拉丁 *con-*（一起）+ *texere*（编织）→ 前后文织在一起的信息
  - **splitter** = **split**（拆分）+ **-er**
- 构词提示：把过长的 **context** **split（拆开）**，方便喂给 Claude 等有长度限制的模型

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| Context Splitter | 上下文拆分器 |
| context window | 上下文窗口（模型一次能读的长度） |
| split into chunks | 拆成若干块 |
| long context | 长上下文 |

## 4. 常用句子

### 句子 1
> Context Splitter breaks a long document into chunks for Claude.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Context Splitter | 上下文拆分器 |
| breaks … into … | 把…拆成… |
| a long document | 一份长文档 |
| chunks | 块；片段 |
| for Claude | 给 Claude 用 |

**语法拆解**
- 句型：主谓 + break A into B + for …
- 主干：Context Splitter + breaks + document + into + chunks
- 时态 / 语态：一般现在时
- 其他成分：for Claude 表用途

**逐词翻译**

| 词 | 意思 |
|----|------|

| a Context Splitter | 上下文拆分器 |

| may exceed | 可能超出 |

**语法拆解**
- 句型：Without 介词短语 + 主谓宾
- 主干：prompt + may exceed + context window
- 时态 / 语态：一般现在时（情态 may）
- 其他成分：Without a Context Splitter 表条件
