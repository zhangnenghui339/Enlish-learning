# implies

- **音标**：/ɪmˈplaɪz/
- **词性**：v.（imply 的第三人称单数；原形 imply /ɪmˈplaɪ/）
- **首次日期**：2026-08-20
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **意味着；暗示**（v.）
   - 中文：不把话说死，但话里已经折进去另一个意思
   - 英文解释：to fold a meaning into what you say (or into a fact) without spelling it out — the extra idea is in there, even if no one uttered it
2. **表明；间接说明**（v.）
   - 中文：某个现象、数据、行为在「指向」一个结论
   - 英文解释：to point to a conclusion as a natural consequence of the evidence, not as a guess you invented
3. **蕴含；若 A 则 B**（v.）
   - 中文：逻辑上：A 成立就一定带着 B
   - 英文解释：in logic, A implies B means: if A is true, B cannot fail to be true — B is folded inside A

## 2. 原子意思

- **原子**：拉丁 *implicare* = **折进去、缠进去**（*in-* 往里 + *plicare* 折叠）；英语 imply = 把意思**折进**话语或事实里，不摊开说
- **英文取词**：描述动作 —— 把一层意思叠进里面，听的人要自己把褶皱打开
- **中文取词**：描述看起来在干什么 —— 话里藏一层叫**暗示**，事实指向结论叫**意味着 / 表明**，逻辑上装在里面叫**蕴含**
- **所以不是一词多义**：同一个「折进去」；中文才按对象拆成暗示、意味着、蕴含

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **Her tone implies doubt** | 怀疑被折进语气里，没说出口 | 看起来是在「旁敲侧击」→ **暗示** |
| **This implies that…** | 这件事里面已经叠着那个结论 | 看起来是在「等于说」→ **意味着** |
| **Rain implies clouds** | 「下雨」里折着「有云」 | 看起来是必然关系 → **蕴含 / 必然有** |
| **implicit meaning** | 意思一直折着、没摊开 | 中文叫**隐含的** |
| **implication** | 被折进去的那一层 | 中文叫**言外之意 / 含义 / 后果** |

对立面：**explicit** = *ex-* 向外 + 同一条「折」→ 把褶皱拉开、摊在外面 → 中文叫**明确的、说死的**。

听的人那边另有一个动词：**infer**（从褶皱里把意思抽出来）→ 中文叫**推断**。说话/事实 **implies**，听者 **infers**；别把方向记反。

## 3. 词根

- 词根 / 词缀：**im-**（往里）+ **plic- / ply**（折）← 拉丁 *plicare*（折叠）
- 真同源：
  - **imply / implication / implicit** — 折进去 → 暗示；含义；隐含的
  - **explicit** — 折出来、摊开 → 明确的
  - **complicate** — 折在一起 → 变复杂
  - **apply** — 折上去、贴上去 → 应用；申请
  - **reply** — 折回来 → 回复
  - **multiply** — 很多层折上去 → 相乘；增多
  - **deploy** — 把叠好的东西展开 → 部署
- 形近勿混：
  - **infer** — 听者/读者把意思抽出来，方向相反，不是「折进去」
  - **implore** — 恳求，来自 *plorare*（哭着求），跟「折」无关
  - **employ** — 使用 / 雇用，来自 *implicare* 的另一条用法（缠进工作里），日常别跟 imply 混成一个意思
- 构词提示：看见 **plic- / ply / ploit** 先问「是不是折、叠、缠」；**imply** 是往里折，**explicit** 是往外摊

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| this implies that… | 这意味着…… |
| imply that | 暗示 / 意味着…… |
| strongly implies | 强烈意味着 |
| by implication | 言下之意；由此可推 |
| implicit in | 隐含在……里 |
| the implication is that… | 言外之意是…… |
| A implies B | A 蕴含 B（若 A 则 B） |
| imply consent | 暗示同意（如 silence implies consent） |

## 5. 常用句子

### 句子 1
> Silence implies consent.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Silence | 沉默 |
| implies | 意味着 / 暗示（折进去） |
| consent | 同意 |

**语法拆解**
- 句型：主谓宾（谚语结构）
- 主干：Silence + implies + consent
- 时态 / 语态：一般现在时（第三人称单数 implies）
- 其他成分：没有把「同意」说出来，但沉默里已经折进了同意

### 句子 2
> The drop in usage implies that the new flow is confusing.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The drop | 这次下降 |
| in usage | 在使用量上 |
| implies | 意味着 |
| that | （引导从句） |
| the new flow | 新流程 |
| is confusing | 是令人困惑的 |

**语法拆解**
- 句型：主谓 + that 宾语从句
- 主干：The drop + implies + that…
- 时态 / 语态：一般现在时
- 其他成分：in usage 修饰 drop；that 从句是被折进数据里的那个结论

### 句子 3
> He implied it; I inferred it.

**逐词翻译**

| 词 | 意思 |
|----|------|
| He | 他 |
| implied | 暗示了（把意思折进去） |
| it | 这件事 |
| I | 我 |
| inferred | 推断出（把意思抽出来） |
| it | 这件事 |

**语法拆解**
- 句型：两个并列分句，对比方向
- 主干：He + implied + it // I + inferred + it
- 时态 / 语态：一般过去时
- 其他成分：同一层意思：说话人折进去，听的人抽出来；中文分别说「暗示」和「推断」
