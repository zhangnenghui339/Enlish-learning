# omnipotent

- **音标**：/ɒmˈnɪpətənt/（英）/ɑːmˈnɪpətənt/（美）
- **词性**：adj.
- **首次日期**：2026-09-14
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **全能的；无所不能的**（adj.）
   - 中文：什么都能做成、什么都能管住，没有做不到的
   - 英文解释：having unlimited power; able to do or control everything, with nothing standing outside your reach
2. **（神）全能的**（adj.）
   - 中文：宗教里用来形容上帝：全知全能的那一位
   - 英文解释：used of God — the one whose power has no limit; the Almighty
3. **（心理）全能的；自以为能掌控一切的**（adj.）
   - 中文：婴儿或自恋里那种「我一想，世界就得听我的」的感觉
   - 英文解释：in psychology, a fantasy that you can control people and reality completely — often as a defense against feeling small or helpless

## 2. 原子意思

- **原子**：拉丁 *omnipotens* = **全部的力量都在手里**（*omni-* 全部 + *potens* 有力的、能做成的）
- **英文取词**：描述力量的性状 —— **没有边界**：能做、能管、能压住一切
- **中文取词**：描述看起来在说谁 —— 说上帝叫**全能**，说人狂叫**无所不能**，说心理防御叫**全能感**
- **所以不是一词多义**：同一个「力量盖住全部」；中文才按对象拆词

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **an omnipotent God** | 力量盖住宇宙，没有例外 | 宗教对象 → **全能的（神）** |
| **he acts as if he were omnipotent** | 人把自己的力量边界抹掉 | 看起来是狂 → **无所不能 / 万能** |
| **infantile omnipotence** | 婴儿还分不清「我想」和「世界」 | 心理学术语 → **婴儿全能感** |
| **omnipotent control** | 用幻想把别人、现实按住 | 防御机制 → **全能控制** |

名词 **omnipotence** = 那种「力量没有外边」的状态 → 中文叫**全能 / 全能感**。

## 3. 词根

- 词根 / 词缀：**omni-** ← 拉丁 *omnis*（全部）+ **pot-** ← *potens / posse*（有力、能够）+ **-ent**（……的）
- 真同源：
  - **potent** — 强有力的；药效猛的
  - **potential** — 潜在的力量（还没使出来）
  - **possible / possibility** — 能做成的 → 可能
  - **power** — 力量（同一条「能」的家族，经法语进来）
  - **impotent** — 没有力量；无能为力
  - **omniscient** — 全知的（*omni-* + *scient* 知道）
  - **omnivore** — 什么都吃（*omni-* + *vorare* 吃）
- 形近勿混：
  - **omnibus** — 公共马车 / 选集，是「给所有人的」，跟「力量」无关
  - **impudent** — 无礼的，来自 *pudere*（羞耻），不是 impotent
- 构词提示：看见 **omni-** 先问「是不是全部」；看见 **pot- / poss- / pow-** 先问「是不是能、有力」；两截叠在一起才是 omnipotent

## 5. 常用句子

### 句子 1
> In many religions, God is described as omnipotent.

**逐词翻译**

| 词 | 意思 |
|----|------|
| In many religions | 在许多宗教里 |
| God | 上帝 |
| is described as | 被描述为 |
| omnipotent | 全能的 |

**语法拆解**
- 句型：主谓 + as 补足语
- 主干：God + is described as + omnipotent
- 时态 / 语态：一般现在时，被动语态
- 其他成分：In many religions 地点/范围状语

### 句子 2
> The toddler feels omnipotent until the world says no.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The toddler | 这个学步小孩 |
| feels | 感觉自己 |
| omnipotent | 无所不能 |
| until | 直到 |
| the world | 这个世界 |
| says no | 说不 |

**语法拆解**
- 句型：主系表 + until 时间从句
- 主干：The toddler + feels + omnipotent
- 时态 / 语态：一般现在时（讲发展规律）
- 其他成分：until 从句标出全能感被现实撞破的时刻

### 句子 3
> His omnipotent fantasies collapsed when he lost the deal.

**逐词翻译**

| 词 | 意思 |
|----|------|
| His | 他的 |
| omnipotent fantasies | 全能幻想 |
| collapsed | 崩塌了 |
| when | 当……时 |
| he lost the deal | 他丢掉了这笔生意 |

**语法拆解**
- 句型：主谓 + when 时间从句
- 主干：His omnipotent fantasies + collapsed
- 时态 / 语态：一般过去时
- 其他成分：omnipotent 作 fantasies 的定语；when 从句给出崩塌的触发点
