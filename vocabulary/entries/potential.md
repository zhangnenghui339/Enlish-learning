# potential

- **音标**：/pəˈtenʃl/
- **词性**：n. / adj.
- **首次日期**：2026-08-15
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁 *potentia*（力量、能力）← *potens*（有力的）
- 构词提示：有「潜在力量」→ 名词：潜力；形容词：潜在的、可能的  
  相关：**potentially**（潜在地）；**potentiality**（可能性，较正式）

## 2. 高频常用意思

1. **潜力；潜能**（n.）— qualities that may develop and lead to future success
2. **潜在的；可能的**（adj.）— possible or likely in the future, but not yet real
3. **可能性**（n.）— the chance that something may happen（常与 of / for 连用）

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| have / show potential | 有 / 展现潜力 |
| potential customer / market | 潜在客户 / 市场 |
| full potential | 全部潜力 |
| the potential for / of… | ……的可能性 |
| high-potential | 高潜力的 |

## 4. 常用句子

### 句子 1
> This approach has strong potential to become profitable.

**逐词翻译**

| 词 | 意思 |
|----|------|
| This approach | 这种方法 |
| has | 有 |
| strong potential | 很强的潜力 |
| to become | 变成 |
| profitable | 盈利的 |

**语法拆解**
- 句型：主语 + have + 宾语 + to 不定式
- 主干：This approach + has + strong potential
- 时态 / 语态：一般现在时
- 其他成分：to become profitable 说明潜力方向；呼应已学 approach / profitable

### 句子 2
> We need validation before we call them potential customers.

**逐词翻译**

| 词 | 意思 |
|----|------|
| We | 我们 |
| need | 需要 |
| validation | 验证 |
| before | 在……之前 |
| we call them | 我们称他们为 |
| potential customers | 潜在客户 |

**语法拆解**
- 句型：主句 + before 时间从句
- 主干：We + need + validation
- 时态 / 语态：一般现在时
- 其他成分：potential 作形容词修饰 customers

### 句子 3
> Don't ignore the potential trap of promising more than you are delivering.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Don't | 不要 |
| ignore | 忽视 |
| the potential trap | 潜在的陷阱 |
| of promising | 承诺……的 |
| more than | 比……更多 |
| you are delivering | 你正在交付的 |

**语法拆解**
- 句型：祈使否定 + of 动名词短语
- 主干：Don't ignore the potential trap
- 时态 / 语态：祈使语气；从句现在进行时
- 其他成分：potential 修饰 trap = 可能出现的圈套；呼应已学 trap / delivering
