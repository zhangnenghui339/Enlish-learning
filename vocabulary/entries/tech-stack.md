# tech stack

- **音标**：/tek stæk/
- **词性**：n. phrase
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：**tech**（technology）+ **stack**（堆叠；一整套）
- 构词提示：项目/公司用的那一套技术组合（语言、框架、数据库、云等）

## 2. 高频常用意思

1. **技术栈**（n.）— the set of technologies used to build a product
2. **（招聘）岗位技术要求组合**（n.）— e.g. React + Node + AWS

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| modern tech stack | 现代技术栈 |
| match the tech stack | 匹配技术栈 |
| full tech stack | 完整技术栈 |
| change the tech stack | 更换技术栈 |

## 4. 常用句子

### 句子 1
> What's your preferred tech stack?

**逐词翻译**

| 词 | 意思 |
|----|------|
| What's | 什么是 |
| your | 你的 |
| preferred | 偏好的 |
| tech stack | 技术栈 |

**语法拆解**
- 句型：特殊疑问句
- 主干：What is + your preferred tech stack
- 时态 / 语态：一般现在时
- 其他成分：preferred 修饰 tech stack

### 句子 2
> The job requires experience with our tech stack.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The job | 这份工作 |
| requires | 要求 |
| experience | 经验 |
| with | 关于 / 使用 |
| our tech stack | 我们的技术栈 |

**语法拆解**
- 句型：主谓宾
- 主干：The job + requires + experience
- 时态 / 语态：一般现在时
- 其他成分：with our tech stack 修饰 experience
