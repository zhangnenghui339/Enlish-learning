# illusion

- **音标**：/ɪˈluːʒn/
- **词性**：n.
- **首次日期**：2026-09-08
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **错觉；幻觉**（n.）
   - 中文：眼睛或脑子以为看见了真的，其实没有
   - 英文解释：something that looks or feels real to the senses, but is not actually there that way
2. **假象**（n.）
   - 中文：局面看起来是某种样子，底下不是
   - 英文解释：a false appearance; a situation that seems true or safe until you look closer
3. **幻想；不切实际的想法**（n.）
   - 中文：心里当成真的希望或信念，其实站不住
   - 英文解释：a false belief or hope you hold onto, even though it does not match reality

## 2. 原子意思

- **原子**：拉丁 *ludere* = **玩、演戏**；*il-ludere* = 对着某人玩一把、拿感官开玩笑；**illusion** = **被玩出来的那一场戏**（看起来真，其实是戏法）
- **英文取词**：描述它**动起来**什么样 —— 感官或脑子被「玩」了一下，画面先成立，再被拆穿
- **中文取词**：描述它**看起来**是哪一类 —— 眼睛被玩叫错觉，局面被玩叫假象，希望被玩叫幻想
- **所以不是一词多义**：同一个「被戏法罩住」；中文才拆成错觉、假象、幻想

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **optical illusion** | 眼睛被玩：线条/颜色看起来在动、在弯 | 看起来是「看错了」→ **视错觉** |
| **an illusion of safety** | 局面被玩：表面安稳，底下不稳 | 看起来是「装出来的样子」→ **假象** |
| **under the illusion that…** | 脑子被玩：把假的当成真的信着 | 看起来是「误以为」→ **幻想 / 错觉** |
| **disillusion** | 把这场戏拆掉，戏法失效 | 中文改口说 **幻灭**，不再用「幻觉」 |

魔术里的 *illusion* 仍是同一原子：当众把感官玩一遍，让你看见不可能的事。

## 3. 词根

- 词根 / 词缀：**il-**（对着、朝上）+ **lus- / lud-** ← 拉丁 *ludere*（玩、演戏）+ **-ion**（名词）→ 对着你玩出来的那场戏
- 真同源（都从「玩」长出来）：
  - **illusive / illusory** — 虚幻的；靠戏法撑着的
  - **disillusion** — 拆掉戏法 → 幻灭
  - **delude / delusion** — 把人玩进假信念里 → 欺骗 / 妄想
  - **elude / elusive** — 玩着躲开 → 逃避 / 难以抓住
  - **allude / allusion** — 朝某个方向玩一下 → 暗示、典故
  - **collude / collusion** — 一起演戏 → 串通
  - **prelude / interlude** — 开场戏 / 中间插的一段
  - **ludicrous** — 本来是「好玩的」，后来变成「荒唐可笑」
- 形近勿混：
  - **allusion**（暗示）vs **illusion**（错觉）— 都从 *ludere* 来，方向不同：allude 是「朝那边点一下」，illusion 是「把你玩进假画面」；拼写差一个字母，意思差很远
  - **illustration** — 拉丁 *illustrare*（照亮）→ 插图、说明；**不是**「玩」
- 构词提示：看见 **lud- / lus-** 先问「是不是在玩、在演戏」；能对上的才是亲戚。**illusion / allusion** 要按方向记，不要靠长得像硬背

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| optical illusion | 视错觉 |
| an illusion of… | ……的假象 |
| under the illusion that… | 误以为……；幻想着…… |
| create / maintain an illusion | 制造 / 维持假象 |
| shatter / dispel an illusion | 打破假象；拆穿幻觉 |
| harbor no illusions | 不抱幻想 |
| illusory | 虚幻的；靠假象撑着的 |
| disillusioned | 幻灭的；不抱幻想了 |

## 5. 常用句子

### 句子 1
> The painting is an optical illusion.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The painting | 这幅画 |
| is | 是 |
| an optical illusion | 一种视错觉 |

**语法拆解**
- 句型：主系表
- 主干：The painting + is + an illusion
- 时态 / 语态：一般现在时
- 其他成分：optical 标明「玩」的是眼睛，不是局面或希望

### 句子 2
> Don't be under the illusion that this will be easy.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Don't | 不要 |
| be | 处于 |
| under the illusion | 被这场戏罩着 / 误以为 |
| that | 引导以为的内容 |
| this | 这件事 |
| will be | 将会是 |
| easy | 容易的 |

**语法拆解**
- 句型：祈使句 + that 从句
- 主干：Don't be under the illusion
- 时态 / 语态：祈使语气；从句用一般将来时
- 其他成分：under the illusion that… 是固定说法，等于「脑子被玩进一个假信念」

### 句子 3
> The calm was only an illusion of safety.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The calm | 这份平静 |
| was | 是 |
| only | 只不过 |
| an illusion of safety | 安全的假象 |

**语法拆解**
- 句型：主系表
- 主干：The calm + was + an illusion
- 时态 / 语态：一般过去时
- 其他成分：of safety 标明假象装成什么；only 把「看起来真」往回拆
