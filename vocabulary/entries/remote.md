# remote

- **音标**：/rɪˈməʊt/
- **词性**：adj. / adv. / n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁 *remotus*（移开的、远离的）← re- + movēre（移动）
- 构词提示：距离远的 → 远程办公；也可指遥控器（remote control）

## 2. 高频常用意思

1. **远程的**（adj.）— done from a distance；remote work / remote job
2. **偏远的**（adj.）— far away in place
3. **（口语）远程岗位 / 远程办公**（n.）— looking for remote

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| remote work / job | 远程工作 / 远程岗位 |
| remote-first | 远程优先 |
| fully remote | 全远程 |
| hybrid / remote | 混合 / 远程 |
| work remotely | 远程办公 |

## 4. 常用句子

### 句子 1
> This is a fully remote role.

**逐词翻译**

| 词 | 意思 |
|----|------|
| This | 这 |
| is | 是 |
| a | 一个 |
| fully remote | 全远程的 |
| role | 岗位 |

**语法拆解**
- 句型：主系表
- 主干：This + is + a fully remote role
- 时态 / 语态：一般现在时
- 其他成分：fully 强化 remote

### 句子 2
> More companies are hiring remote engineers.

**逐词翻译**

| 词 | 意思 |
|----|------|
| More companies | 更多公司 |
| are hiring | 正在招聘 |
| remote | 远程的 |
| engineers | 工程师 |

**语法拆解**
- 句型：主谓宾
- 主干：More companies + are hiring + remote engineers
- 时态 / 语态：现在进行时
- 其他成分：remote 作定语
