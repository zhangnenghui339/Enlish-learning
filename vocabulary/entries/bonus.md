# bonus

- **音标**：/ˈbəʊnəs/
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁 *bonus*（好的）→ 额外的好处
- 构词提示：基本工资之外多给的一笔；常见 **signing bonus**（签字奖）、**annual bonus**（年终奖）

## 2. 高频常用意思

1. **奖金**（n.）— extra pay on top of salary
2. **额外好处**（n.）— an unexpected extra benefit

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| signing bonus | 签字奖金 / 入职奖金 |
| annual / performance bonus | 年度 / 绩效奖金 |
| bonus package | 奖金方案 |
| eligible for a bonus | 有资格拿奖金 |

## 4. 常用句子

### 句子 1
> The offer includes a $10,000 signing bonus.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The offer | 这份录用条件 |
| includes | 包含 |
| a $10,000 | 一万美元的 |
| signing bonus | 签字奖金 |

**语法拆解**
- 句型：主谓宾
- 主干：The offer + includes + a signing bonus
- 时态 / 语态：一般现在时
- 其他成分：$10,000 修饰金额
