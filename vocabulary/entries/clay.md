# clay

- **音标**：/kleɪ/
- **词性**：n. / proper n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：古英语 *clǣg*（黏土）
- 构词提示：日常义是泥土/陶土；商业搜索里 **Clay** 常指数据 enrichment / GTM 工具 **Clay.com**，故有 *Clay alternative*

## 2. 高频常用意思

1. **黏土；陶土**（n.）— soft earth used for pottery
2. **Clay（产品名）**（proper n.）— a popular go-to-market / data enrichment platform；people often look for alternatives

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| Clay alternative | Clay 的替代产品 |
| modeling clay | 橡皮泥 / 造型黏土 |
| clay pot | 陶罐 |
| switch from Clay | 从 Clay 换走 |

## 4. 常用句子

### 句子 1
> Clay is powerful, but some teams want a cheaper alternative.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Clay | Clay（产品） |
| is | 是 |
| powerful | 强大的 |
| but | 但是 |
| some teams | 一些团队 |
| want | 想要 |
| a cheaper alternative | 一个更便宜的替代方案 |

**语法拆解**
- 句型：并列转折句
- 主干：Clay is powerful / some teams want a cheaper alternative
- 时态 / 语态：一般现在时
- 其他成分：cheaper 修饰 alternative

### 句子 2
> The sculpture was made of clay.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The sculpture | 这座雕塑 |
| was made | 被制成 |
| of | 由……制成 |
| clay | 黏土 |

**语法拆解**
- 句型：被动语态
- 主干：The sculpture + was made of + clay
- 时态 / 语态：一般过去时被动
- 其他成分：of clay 表材料
