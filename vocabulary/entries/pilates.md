# Pilates

- **音标**：/pɪˈlɑːtiːz/
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：专有名词，来自创始人 **Joseph Pilates** 的姓氏
- 构词提示：不是普通词根词；他原称这套方法为 Contrology（控制学），后人用其姓氏称呼 → Pilates

## 2. 高频常用意思

1. **普拉提**（n.）— 强调核心力量、呼吸与身体控制的健身法；a low-impact exercise system focused on core control
2. **普拉提课 / 训练**（n.）— 也可指课程本身；a Pilates class or session

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| do Pilates | 练普拉提 |
| take a Pilates class | 上普拉提课 |
| Pilates instructor / teacher | 普拉提教练 |
| mat Pilates | 垫上普拉提 |
| Reformer Pilates | 器械普拉提 |
| low-impact workout | 低冲击训练 |

## 4. 常用句子

### 句子 1
> I do Pilates twice a week.

**逐词翻译**

| 词 | 意思 |
|----|------|
| I | 我 |
| do | 做 / 练 |
| Pilates | 普拉提 |
| twice | 两次 |
| a | 每一 |
| week | 周 |

**语法拆解**
- 句型：主谓宾 + 频率状语
- 主干：I + do + Pilates
- 时态 / 语态：一般现在时（习惯）
- 其他成分：twice a week 表频率

### 句子 2
> Pilates helps improve posture and flexibility.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Pilates | 普拉提 |
| helps | 帮助 |
| improve | 改善 |
| posture | 体态 / 姿势 |
| and | 和 |
| flexibility | 柔韧性 |

**语法拆解**
- 句型：主语 + 谓语 + 不带 to 的不定式宾语
- 主干：Pilates + helps + improve …
- 时态 / 语态：一般现在时
- 其他成分：posture and flexibility 为 improve 的并列宾语
