# trend

- **音标**：/trend/
- **词性**：n. / v.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：中古英语 *trenden*（转动、转向）→ 引申为“走向、倾向”
- 构词提示：事物“转向某个方向” = 趋势；常与 **velocity** 组成 **trend velocity**（趋势升温/扩散的速度）

## 2. 高频常用意思

1. **趋势；潮流**（n.）— a general direction in which something is developing or changing
2. **倾向；走向**（n.）— a pattern over time, e.g. an upward trend
3. **趋向；倾向**（v.）— to develop in a particular direction；prices are trending up

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| trend velocity | 趋势速度（趋势升温/扩散有多快） |
| upward / downward trend | 上升 / 下降趋势 |
| follow the trend | 跟随潮流 |
| set a trend | 引领潮流 |
| trending topic | 热门话题 |
| market trend | 市场趋势 |

## 4. 常用句子

### 句子 1
> This product is riding a strong market trend.

**逐词翻译**

| 词 | 意思 |
|----|------|
| This | 这个 |
| product | 产品 |
| is riding | 正搭上 / 正乘着 |
| a | 一股 |
| strong | 强劲的 |
| market | 市场 |
| trend | 趋势 |

**语法拆解**
- 句型：主谓宾
- 主干：This product + is riding + a strong market trend
- 时态 / 语态：现在进行时
- 其他成分：strong、market 修饰 trend；ride a trend = 借势

### 句子 2
> Brands watch trend velocity to decide when to enter a category.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Brands | 品牌们 |
| watch | 观察 |
| trend | 趋势 |
| velocity | 速度 |
| to decide | 以便决定 |
| when | 何时 |
| to enter | 进入 |
| a category | 一个品类 |

**语法拆解**
- 句型：主语 + 谓语 + 宾语 + 目的状语
- 主干：Brands + watch + trend velocity
- 时态 / 语态：一般现在时
- 其他成分：to decide… 表目的；when to enter… 为 decide 的宾语
