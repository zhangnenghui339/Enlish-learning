# wrapper

- **音标**：/ˈræpər/
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：wrap（包裹、包起来）+ -er（……的人或物）
- 构词提示：用来“包住”别的东西的那一层 → 包装纸 / 外壳 /（编程里）封装层  
  动词：**wrap**；过去式 wrapped

## 2. 高频常用意思

1. **包装纸；包装物**（n.）— paper or material that covers something, e.g. a candy wrapper
2. **（软件）封装层；包装器**（n.）— code that wraps another API/library to make it easier to use
3. **外套式覆盖物**（n.）— anything that covers or encloses something else

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| candy / chocolate wrapper | 糖纸 / 巧克力包装纸 |
| plastic wrapper | 塑料包装 |
| API wrapper | API 封装层 |
| function wrapper | 函数包装器 |
| remove the wrapper | 去掉包装 / 去掉封装层 |

## 4. 常用句子

### 句子 1
> Don't leave the candy wrapper on the table.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Don't | 不要 |
| leave | 留下 |
| the | 这个 |
| candy | 糖果 |
| wrapper | 包装纸 |
| on | 在……上 |
| the table | 桌子 |

**语法拆解**
- 句型：祈使句（否定）
- 主干：(You) + don't leave + the candy wrapper
- 时态 / 语态：祈使语气
- 其他成分：on the table 表地点

### 句子 2
> We built a wrapper around the payment API.

**逐词翻译**

| 词 | 意思 |
|----|------|
| We | 我们 |
| built | 构建了 |
| a | 一个 |
| wrapper | 封装层 |
| around | 围绕 |
| the payment API | 支付接口 |

**语法拆解**
- 句型：主谓宾 + 介词短语
- 主干：We + built + a wrapper
- 时态 / 语态：一般过去时
- 其他成分：around the payment API 说明封装对象
