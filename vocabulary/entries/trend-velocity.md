# trend velocity

- **音标**：/trend vəˈlɒsəti/
- **词性**：n. phrase（商业用语）
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：**trend**（趋势）+ **velocity**（veloc- 快 + -ity）
- 构词提示：不是“趋势本身”，而是**趋势升温/扩散有多快**；用来判断要不要跟、何时进场  
  相关条目：`trend.md`、`velocity.md`

## 2. 高频常用意思

1. **趋势速度**（n.）— how fast a trend is rising, spreading, or gaining attention
2. **（品类/话题的）热度爬升速率**（n.，商业）— a signal for timing entry into an emerging category

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| high trend velocity | 趋势速度很快 / 热度蹿升快 |
| measure trend velocity | 衡量趋势速度 |
| accelerating trend velocity | 趋势速度在加快 |
| low trend velocity | 趋势升温慢 |
| trend velocity in a category | 某品类的趋势速度 |

## 4. 常用句子

### 句子 1
> Investors track trend velocity before entering an emerging category.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Investors | 投资者 |
| track | 追踪 |
| trend velocity | 趋势速度 |
| before | 在……之前 |
| entering | 进入 |
| an | 一个 |
| emerging | 新兴的 |
| category | 品类 |

**语法拆解**
- 句型：主语 + 谓语 + 宾语 + 时间状语
- 主干：Investors + track + trend velocity
- 时态 / 语态：一般现在时
- 其他成分：before entering… 表时机

### 句子 2
> High trend velocity can fade quickly if there is no real demand.

**逐词翻译**

| 词 | 意思 |
|----|------|
| High | 高的 |

**语法拆解**

- 其他成分：quickly 修饰 fade；if 从句表条件
