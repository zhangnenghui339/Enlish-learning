# alternative

- **音标**：/ɔːlˈtɜːrnətɪv/
- **词性**：n. / adj.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁 *alternare*（交替）→ alter-（另一个）+ -native
- 构词提示：可替换的另一个选择；**Clay alternative** = Clay 的替代产品  
  同源：alternate（交替的 / 轮流）

## 2. 高频常用意思

1. **替代方案；备选**（n.）— another option you can choose instead
2. **可供选择的；替代的**（adj.）— different from the usual one；an alternative plan

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| an alternative to... | ……的替代方案 |
| Clay alternative | Clay 的替代产品 |
| no alternative | 别无选择 |
| alternative solution | 替代解决方案 |
| consider alternatives | 考虑其他选项 |

## 4. 常用句子

### 句子 1
> People are searching for a Clay alternative.

**逐词翻译**

| 词 | 意思 |
|----|------|
| People | 人们 |
| are searching | 正在搜索 |
| for | 寻找 |
| a | 一个 |
| Clay | Clay（产品名） |
| alternative | 替代方案 |

**语法拆解**
- 句型：主谓 + 介词宾语
- 主干：People + are searching for + a Clay alternative
- 时态 / 语态：现在进行时
- 其他成分：Clay 作名词定语修饰 alternative

### 句子 2
> Is there an affordable alternative to this tool?

**逐词翻译**

| 词 | 意思 |
|----|------|
| Is there | 有没有 |
| an | 一个 |
| affordable | 可负担的 |
| alternative | 替代方案 |
| to | 相对于 |
| this tool | 这个工具 |

**语法拆解**
- 句型：There be 疑问句
- 主干：Is there + an affordable alternative
- 时态 / 语态：一般现在时
- 其他成分：to this tool 限定替代对象
