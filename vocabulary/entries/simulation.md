# simulation

- **音标**：/ˌsɪmjuˈleɪʃn/（亦作 /ˌsɪmjəˈleɪʃən/）
- **词性**：n.
- **首次日期**：2026-09-14
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **模拟；仿真**（n.）
   - 中文：做出一个「像真的那样转」的副本，用来试、用来练、用来预测
   - 英文解释：a working likeness of a real process — you run a copy so you can test, train, or predict without using the real thing
2. **假装；装出来的**（n.）
   - 中文：外表像，底下不是；演出来的症状、演出来的热情
   - 英文解释：the act of pretending; making something look like the real feeling or state when it is not
3. **（计算机）仿真运行**（n.）
   - 中文：用程序把系统一步步演一遍
   - 英文解释：running a model on a computer so the system’s behavior unfolds over time

## 2. 原子意思

- **原子**：拉丁 *similis* = **像**；*simulare* = **做成像真的那样**
- **英文取词**：描述动作 —— **造一个像**：可以当真用（仿真），也可以只是罩一层像（假装）
- **中文取词**：工程/科学叫**模拟 / 仿真**，骗人/演戏叫**假装**，电脑里跑模型叫**仿真运行**
- **所以不是一词多义**：同一个「做成像」；中文才按目的拆成不同词

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **flight simulation** | 造一个像真飞的环境来练 | **飞行模拟** |
| **climate simulation** | 让气候的像在电脑里转 | **气候模拟 / 仿真** |
| **simulation of illness** | 把病「做得像」 | **装病** |
| **agency simulation** | 把「能自己做事」做得像 | **能动性模拟** |

动词 **simulate** = 这个「做成像」的动作；形容词 **simulated** = 仿的、不是真的那份。

## 3. 词根

- 词根 / 词缀：**simul- / simil-** ← 拉丁 *similis*（像）+ **-ation**（行为 / 结果）
- 真同源：
  - **similar / similarity** — 像的；相似性
  - **simulate** — 模拟；假装
  - **simile** — 明喻（A 像 B）
  - **simultaneous** — 同一时候（*simul* 一起）
  - **resemble** — 看起来像（re- + similare 经法语）
  - **dissemble** — 把「像」藏起来 → 掩饰
- 形近勿混：
  - **stimulate / stimulus** — 刺激，来自「刺、催」，**不是**「像」
  - **simple** — 简单，来自 *simplex*（一重的），别和 similar 捆成一家记
  - **assimilation** — 同化，倒是亲戚（做成一样、吸收成自己）
- 构词提示：看见 **simil- / simul-** 先问「是不是像、一起做成像」；**stimul-** 是刺，不是像

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| computer / flight simulation | 计算机 / 飞行模拟 |
| run a simulation | 跑一次模拟 |
| simulated environment | 模拟环境 |
| simulation of agency | 对能动性的模拟 |
| a mere simulation | 只不过是装出来的 |
| simulate a process | 模拟某个过程 |

## 5. 常用句子

### 句子 1
> They ran a simulation before launching the product.

**逐词翻译**

| 词 | 意思 |
|----|------|
| They | 他们 |
| ran | 跑了 / 进行了 |
| a simulation | 一次模拟 |
| before | 在……之前 |
| launching the product | 发布产品 |

**语法拆解**
- 句型：主谓宾 + before 时间状语
- 主干：They + ran + a simulation
- 时态 / 语态：一般过去时
- 其他成分：before… 标出「先做成像，再动真的」

### 句子 2
> The smile was a simulation of warmth, not warmth itself.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The smile | 这个微笑 |
| was | 是 |
| a simulation | 一种装出来的像 |
| of warmth | 关于温暖的 |
| not warmth itself | 不是温暖本身 |

**语法拆解**
- 句型：主系表 + 否定对照
- 主干：The smile + was + a simulation
- 时态 / 语态：一般过去时
- 其他成分：of warmth 标出「像」的是哪一种；not… 把像和真拆开

### 句子 3
> A good simulation behaves like the real system under stress.

**逐词翻译**

| 词 | 意思 |
|----|------|
| A good simulation | 一次好的模拟 |
| behaves | 表现得 |
| like the real system | 像真实系统那样 |
| under stress | 在压力下 |

**语法拆解**
- 句型：主谓 + like 比较 + 条件状语
- 主干：A good simulation + behaves
- 时态 / 语态：一般现在时（评价标准）
- 其他成分：like… 点出原子「像」；under stress 是考验像不像的条件
