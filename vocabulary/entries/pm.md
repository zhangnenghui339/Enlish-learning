# PM

- **音标**：/ˌpiː ˈem/
- **词性**：n. (abbr.)
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：缩写，科技招聘里最常见 = **Product Manager**（产品经理）  
  也可能是 Project Manager（项目经理）或更少见的 Program Manager——看上下文
- 构词提示：和 Frontend/Backend 并列出现时，通常指产品经理，负责做什么、为什么做，不主写代码

## 2. 高频常用意思

1. **产品经理**（n.）— Product Manager；owns roadmap, requirements, priorities
2. **项目经理**（n.，次常见）— Project Manager；owns timeline and delivery

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| Product Manager (PM) | 产品经理 |
| PM interview | 产品经理面试 |
| work with PMs | 和产品经理合作 |
| PM / Eng collaboration | 产品与工程协作 |

## 4. 常用句子

### 句子 1
> The PM defines the roadmap; engineers build it.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The PM | 产品经理 |
| defines | 定义 |
| the roadmap | 路线图 |
| engineers | 工程师们 |
| build | 构建 |
| it | 它（路线图上的产品） |

**语法拆解**
- 句型：并列句（分号连接）
- 主干：The PM + defines + the roadmap / engineers + build + it
- 时态 / 语态：一般现在时
- 其他成分：对比职责分工
