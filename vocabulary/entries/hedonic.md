# hedonic

- **音标**：/hɪˈdɒnɪk/（美 /hɪˈdɑːnɪk/）
- **词性**：adj.
- **首次日期**：2026-09-08
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **享乐的；追求快感的**（adj.）
   - 中文：跟「爽、舒服、感官被取悦」直接相关，不是为了有用
   - 英文解释：relating to pleasure, especially the kind you feel in the body or mood — nice, sweet, enjoyable for its own sake
2. **（心理 / 经济）快感型的；享乐价值的**（adj.）
   - 中文：用来量「这件事给人多少快感」，相对的是实用
   - 英文解释：in psychology and economics, about how much pleasure something delivers, as opposed to how useful it is
3. **快感会回落的（hedonic adaptation / treadmill）**（adj.，多在固定搭配里）
   - 中文：高兴一阵子，人又回到原来的快乐水平
   - 英文解释：the mind gets used to a good thing, so the pleasure fades and you need another boost to feel the same high

## 2. 原子意思

- **原子**：希腊 *hēdonē* = **那一口甜、爽、舒服**（感官被取悦）；同源更早是 *hēdys* = **甜的**
- **英文取词**：描述它**动起来**什么样 —— 身体或心情被甜到、被爽到；快感自己会涨、也会被习惯掉
- **中文取词**：描述它**看起来**是哪一类 —— 日常叫享乐，买东西叫好看/好玩，心理学叫快感适应
- **所以不是一词多义**：同一个「被甜到」；中文才拆成享乐、快感、实用的反面

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **hedonic pleasure** | 快感本身：吃、听、看、摸带来的爽 | 看起来是「图舒服」→ **享乐** |
| **hedonic vs utilitarian value** | 买它是因为爽，不是因为有用 | 看起来是商品的两种价值 → **享乐价值 / 实用价值** |
| **hedonic treadmill** | 爽过之后习惯了，快乐水位掉回去，又要再跑一圈 | 看起来像跑步机停不下来 → **快乐跑步机 / 快感适应** |
| **anhedonia** | *a-*（没有）+ 甜/爽 → 甜不起来 | 医学上另起一词 → **快感缺失** |

名词 **hedonism** 是同一原子立成主义：把「被甜到」当成人生目标。

## 3. 词根

- 词根 / 词缀：**hedon-** ← 希腊 *hēdonē*（快感）← *hēdys*（甜的）+ **-ic**（形容词）
- 真同源：
  - **hedonism / hedonist** — 享乐主义 / 享乐主义者
  - **anhedonia** — 没有快感
  - **sweet** — 更远的印欧同源：希腊「甜」和英语 *sweet* 是同一条根
  - **suave** — 拉丁 *suavis*（甜、悦人）→ 说话很顺耳
- 形近勿混：
  - **hegemonic** — 希腊 *hēgemōn*（领袖）→ 霸权的；**不是**快感
  - **harmonic** — 和谐；只是尾巴都叫 -onic
  - **ironic** — 反讽；无关
- 构词提示：看见 **hedon-** 先问「是不是甜、爽、感官被取悦」；**an-hedon-ia** 就是甜不起来。不要跟 hegemonic 混成「霸权式享乐」

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| hedonic pleasure | 享乐快感 |
| hedonic experience | 享乐体验（为了爽，不是为了用） |
| hedonic value | 享乐价值（好看、好玩、好味） |
| utilitarian value | 实用价值（对照项：好用） |
| hedonic adaptation | 快感适应；高兴过了又习惯 |
| hedonic treadmill | 快乐跑步机（适应后要再追下一次爽） |
| hedonic pricing | 享乐定价（把舒适、景观等快感因素算进价格） |
| anhedonia | 快感缺失 |

## 5. 常用句子

### 句子 1
> Shopping can be a hedonic experience, not just a practical one.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Shopping | 购物 |
| can be | 可以是 |
| a hedonic experience | 一种享乐体验 |
| not just | 不只是 |
| a practical one | 一次实用的（购物） |

**语法拆解**
- 句型：主系表 + 对照
- 主干：Shopping + can be + an experience
- 时态 / 语态：一般现在时（表可能性）
- 其他成分：hedonic 标明「为了爽」；not just practical 把实用那一头拧开

### 句子 2
> Hedonic adaptation means we get used to good things.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Hedonic adaptation | 快感适应 |
| means | 意味着 |
| we | 我们 |
| get used to | 习惯于 |
| good things | 好东西 |

**语法拆解**
- 句型：主谓宾（宾语是从句）
- 主干：Hedonic adaptation + means + we get used to…
- 时态 / 语态：一般现在时（定义）
- 其他成分：原子在这里是「甜过之后就不甜了」——快感被习惯掉

### 句子 3
> This phone has utilitarian value, but the camera is mostly hedonic.

**逐词翻译**

| 词 | 意思 |
|----|------|
| This phone | 这部手机 |
| has | 有 |
| utilitarian value | 实用价值 |
| but | 但是 |
| the camera | 摄像头 |
| is | 是 |
| mostly hedonic | 多半是享乐型的 |

**语法拆解**
- 句型：并列句（实用 vs 享乐）
- 主干：The phone + has + value // the camera + is + hedonic
- 时态 / 语态：一般现在时
- 其他成分：but 把同一件商品拆成「好用」和「好玩/好看」两头
