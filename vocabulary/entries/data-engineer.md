# data engineer

- **音标**：/ˈdeɪtə ˌendʒɪnɪər/
- **词性**：n. phrase
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：**data**（数据）+ **engineer**（工程师；来自 engine / ingenium）
- 构词提示：负责把数据管道建好、跑通、可查可用；偏基础设施与 ETL，不太等于做模型的 ML Engineer

## 2. 高频常用意思

1. **数据工程师**（n.）— builds pipelines, warehouses, and reliable data systems
2. **（职责）数据基建岗位**（n.）— moves and prepares data for analysts and ML teams

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| data engineering | 数据工程 |
| data pipeline | 数据管道 |
| hire a data engineer | 招聘数据工程师 |
| data engineer vs data scientist | 数据工程师 vs 数据科学家 |

## 4. 常用句子

### 句子 1
> A data engineer builds pipelines that feed the analytics team.

**逐词翻译**

| 词 | 意思 |
|----|------|
| A data engineer | 一位数据工程师 |
| builds | 构建 |
| pipelines | 管道 |
| that | 引导定语从句 |
| feed | 供给 |
| the analytics team | 分析团队 |

**语法拆解**
- 句型：主谓宾 + 定语从句
- 主干：A data engineer + builds + pipelines
- 时态 / 语态：一般现在时
- 其他成分：that feed… 修饰 pipelines
