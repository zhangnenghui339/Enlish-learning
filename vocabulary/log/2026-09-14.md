# 2026-09-14

今天问了 / 已入库：

- cognitive（认知的 / 思维方面的；原子：cognoscere 彻底知道；同源 recognize / ignore / know；cognate 不是「知道」一家）
- omnipotent（全能的 / 无所不能的；原子：omni- 全部 + potens 有力；同源 potent / possible / impotent）
- narcissism（自恋 / 自恋型人格；原子：那喀索斯被倒影吸住；同源 narcissist；narc 不是亲戚）
- omnipotent narcissism（全能自恋：自恋靠「我无所不能」的幻想来维持）
- assumption（假设 / 承担 / 圣母升天；原子：assumere 朝自己拿过来；同源 assume / consume / presume；assurance 不是亲戚）
- defusion（认知解离 / 去融合；原子：de- + fusion 把熔住的拆开；勿混 diffusion 扩散、defuse 拆引信、delusion 妄想）
- agency（能动性 / 代理机构；原子：agere 做、驱；同源 agent / act / agenda；age 不是亲戚）
- simulation（模拟 / 假装；原子：simulare 做成像；同源 similar / simulate；stimulate 不是亲戚）
- agency simulation（能动性模拟：把「能自己做事」做成一个像；商业语境才可能是「代理公司做的模拟」）
