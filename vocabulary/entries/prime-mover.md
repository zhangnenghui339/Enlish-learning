# prime mover

- **音标**：/ˌpraɪm ˈmuːvər/
- **词性**：n. (compound)
- **首次日期**：2026-08-27
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **原动力；推动者；主导者**（n.）
   - 中文：最先让整件事动起来的那个人或那股力，后面的人都是跟着走
   - 英文解释：the person or force that starts something and keeps it going; others move because this one moved first
2. **原动机**（n.）
   - 中文：给整套机器提供第一股动力的那台发动机（柴油机、蒸汽机、电动机等）
   - 英文解释：the engine or machine that supplies the first mechanical power; everything else in the system is driven by it
3. **第一推动者**（n.）
   - 中文：哲学里那个「自己不动、却让万物动起来」的源头
   - 英文解释：in philosophy, the first cause that sets all motion going without itself being pushed — Latin *primum movens*

## 2. 原子意思

- **原子**：**prime（第一、最先）+ mover（使动起来的那个）** → **链条最前端、让后面全部动起来的那一下**
- **英文取词**：描述位置 —— **运动链的第一环：它动了，别的才动**
- **中文取词**：描述看起来像哪一类东西 —— 人叫**推动者**，机器叫**原动机**，宇宙源头叫**第一推动者**
- **所以不是一词多义**：同一个「最先让别的动起来」；中文才拆成主导者、原动机、第一因

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| the prime mover behind the deal | 这笔交易最先被谁推起来 | 看起来是人事 → **推动者 / 主导者** |
| a diesel prime mover | 柴油机先转，发电机才转 | 看起来是机械 → **原动机** |
| the Prime Mover | 万物运动的第一下，自己却不被推 | 看起来是哲学 → **第一推动者** |
| prime (steak / time) | 还是「第一、最上等」 | 中文改口说**上等 / 黄金（时段）**，不再强调「使动」 |
| first mover | 市场上**最先动手**的人，不是「使别人动」 | 中文叫**先发者**；跟 prime mover **不是同一个意思** |

## 3. 词根

- 词根 / 词缀：
  - **prime** ← 拉丁 *primus*（第一、最先）
  - **mover** ← 拉丁 *movere*（使移动）+ *-er*（发出动作的人 / 物）
  - 拉丁术语 *primum movens* = 第一推动者，后进入机械和日常英语
- 真同源：
  - **primary / primitive / premier / prince** — 都从 *primus*「第一」长出来
  - **move / motion / motor / promote / remote / mobile / momentum** — 都从 *movere*「动」长出来
- 形近勿混：
  - **first mover** — 市场上先出手的人（first-mover advantage 先发优势），不是「使整条链动起来的源头」
  - **mover and shaker** — 有权有势、能搅动局面的人，近义但没有「第一环」这层
  - **primer** — 底漆 / 入门书，来自「第一层」，不是 mover
- 构词提示：拆开看 **第一 + 使动**；先问「谁在链条最前端」——是人、是发动机，还是哲学里的第一因

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| the prime mover behind | ……背后的推动者 |
| a prime mover in | 在……中起主导作用的人 |
| prime mover of change | 变革的原动力 |
| diesel / steam prime mover | 柴油 / 蒸汽原动机 |
| the unmoved / Prime Mover | （哲学）第一推动者 |
| first-mover advantage | 先发优势（对照：不是 prime mover） |

## 5. 常用句子

### 句子 1
> She was the prime mover behind the new policy.

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| was | 是 |
| the prime mover | 最先推动的那个人 |
| behind the new policy | 在这项新政策背后 |

**语法拆解**
- 句型：主系表 + 后置定语
- 主干：She + was + the prime mover
- 时态 / 语态：一般过去时
- 其他成分：behind the new policy 标明她处在哪条运动链的最前端

### 句子 2
> The diesel engine is the prime mover for the generator.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The diesel engine | 这台柴油机 |
| is | 是 |
| the prime mover | 原动机 / 第一股动力 |
| for the generator | 给发电机用的 |

**语法拆解**
- 句型：主系表 + 介词短语
- 主干：The diesel engine + is + the prime mover
- 时态 / 语态：一般现在时
- 其他成分：for the generator 标明谁被它带着转：柴油机先动，发电机才动

### 句子 3
> Aristotle's Prime Mover starts all motion without being moved.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Aristotle's Prime Mover | 亚里士多德所说的第一推动者 |
| starts | 启动 |
| all motion | 一切运动 |
| without being moved | 自己却不被推动 |

**语法拆解**
- 句型：主谓宾 + without 状语
- 主干：the Prime Mover + starts + all motion
- 时态 / 语态：一般现在时（陈述哲理）；being moved 是被动
- 其他成分：without being moved 钉死原子 —— 它是第一环，前面再没有人推它
