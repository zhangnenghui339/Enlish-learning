# engine

- **音标**：/ˈendʒɪn/
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁语 ingenium = in-（在……之中）+ gen-（产生）→ 天生才能、巧妙装置
- 构词提示：同源词 ingenious（巧妙的）、engineer（工程师）、ingenuity（才智）  
  易混：**emerging**（新兴的）= e- + merge（冒出来），词源完全不同

## 2. 高频常用意思

1. **引擎；发动机**（n.）— a machine that converts energy into motion
2. **引擎 / 驱动因素**（n.，引申）— something that drives growth or progress；a growth engine

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| car engine | 汽车发动机 |
| search engine | 搜索引擎 |
| growth engine | 增长引擎 |
| recommendation engine | 推荐引擎 |
| engine of growth | 增长的动力 |

## 4. 常用句子

### 句子 1
> Search is the growth engine of the company.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Search | 搜索 |
| is | 是 |
| the | 这个 |
| growth | 增长 |
| engine | 引擎 |
| of | ……的 |
| the company | 公司 |

**语法拆解**
- 句型：主系表
- 主干：Search + is + the growth engine
- 时态 / 语态：一般现在时
- 其他成分：of the company 修饰 engine

### 句子 2
> The new product could become a major revenue engine.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The | 这个 |
| new | 新的 |
| product | 产品 |
| could | 可能 |
| become | 成为 |
| a | 一个 |
| major | 主要的 |
| revenue | 营收 |
| engine | 引擎 |

**语法拆解**
- 句型：主语 + 情态动词 + 系动词 + 表语
- 主干：The new product + could become + a major revenue engine
- 时态 / 语态：情态 + 原形（表可能）
- 其他成分：major、revenue 修饰 engine
