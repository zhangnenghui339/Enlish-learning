# catalytic converter cleaner

- **音标**：/ˌkætəˈlɪtɪk kənˈvɜːtə ˈkliːnə/
- **词性**：n. phrase（汽车养护产品名）
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **三元催化清洗剂 / 催化转化器清洁剂**（n.）— a chemical product that cleans carbon and deposits from a car’s catalytic converter
2. **catalytic converter**（单独）— 催化转化器（俗称「三元催化」）；把废气中有害气体转化成较无害气体的部件
3. **cleaner**（此处）— 清洁剂；清洗产品（不是「清洁工」）

## 2. 词根

- 词根 / 词缀：
  - **catalytic** ← **catalyst**（催化剂）+ **-ic**（…的）→ 催化的
  - **converter** = **convert**（转化）+ **-er**（做某事的装置）→ 转化器
  - **cleaner** = **clean**（清洁）+ **-er**（工具/剂）→ 清洁剂
- 构词提示：清洁 **catalytic converter（催化转化器）** 的 **cleaner（清洁剂）** → 汽车尾气系统养护用品

## 4. 常用句子

### 句子 1
> This catalytic converter cleaner is added to the fuel tank.

**逐词翻译**

| 词 | 意思 |
|----|------|
| This | 这种 |
| catalytic converter cleaner | 三元催化清洗剂 |
| is added | 被加入 |
| to the fuel tank | 到油箱里 |

**语法拆解**
- 句型：被动语态 + to 介词短语
- 主干：cleaner + is added
- 时态 / 语态：一般现在时，被动
- 其他成分：to the fuel tank 说明加入位置

### 句子 2
> A clogged catalytic converter can trigger the check engine light.

**逐词翻译**

| 词 | 意思 |
|----|------|
| A clogged catalytic converter | 堵塞的三元催化 |
| can | 可能；会 |
| trigger | 触发；引起 |
| the check engine light | 发动机故障灯 |

**语法拆解**
- 句型：主谓宾
- 主干：catalytic converter + can trigger + light
- 时态 / 语态：一般现在时（情态 can）
- 其他成分：clogged 作前置定语，修饰 catalytic converter
