# scraping

- **音标**：/ˈskreɪpɪŋ/
- **词性**：v. / n.（scrape 的现在分词 / 动名词；原形 scrape /skreɪp/）
- **首次日期**：2026-08-21
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **刮；刮掉**（v. / n.）
   - 中文：硬边贴着表面拖过去，把一层东西刮下来
   - 英文解释：dragging a hard edge across a surface so a thin layer comes off — ice off glass, paint off wood, burnt bits off a pan
2. **擦伤；蹭破**（v.）
   - 中文：皮肤或物件被硬物蹭过，表层破了
   - 英文解释：to graze something by rubbing it against a rough surface, taking off a little skin or finish
3. **勉强凑；勉强维持**（v.）
   - 中文：一点一点刮下来才够用，日子过得紧
   - 英文解释：to gather just enough with difficulty, as if you are scraping the last bits off the bottom — money, votes, a passing grade
4. **（网页 / 数据）抓取**（n. / v.）
   - 中文：像刮表面一样，从网页上把公开信息刮下来
   - 英文解释：copying structured information off web pages the way you scrape residue off a surface; in tech, usually called web scraping or data scraping

## 2. 原子意思

- **原子**：日耳曼语 *skrap- / 古诺斯 *skrapa* = **硬边贴着面拖过去，把薄薄一层刮下来**
- **英文取词**：描述动作 —— 贴着表面刮，带走一层，底下往往还剩一点残渣
- **中文取词**：描述看起来在刮哪一类对象 —— 刮冰/刮锅叫**刮**，刮到皮肤叫**擦伤**，刮最后一点钱叫**勉强凑**，刮网页上的字叫**抓取**
- **所以不是一词多义**：同一个「贴着面刮下一层」；中文才按对象拆成不同词

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **scraping ice off the car** | 硬边把冰层刮走 | 看起来是在「除冰」→ **刮掉** |
| **scraped her knee** | 膝盖贴地面被蹭掉一层皮 | 看起来是外伤 → **擦伤 / 蹭破** |
| **scraping by / scraping together $50** | 从桶底把最后一点刮出来才够 | 看起来是经济拮据 → **勉强维持 / 东拼西凑** |
| **web scraping** | 把网页表层的信息刮下来 | 技术语境另起术语 → **网页抓取** |
| **scrape through the exam** | 分数刚擦过及格线 | 中文说**勉强及格 / 擦边过** |

名词 **scrap** = 刮下来的那点残渣、边角料 → 中文叫**废料 / 碎片**；动词 *scrap a plan* 是把东西当废料丢掉 → **作废**。  
名词 **scraper** = 用来刮的工具 / 抓取程序。

## 3. 词根

- 词根 / 词缀：**scrap- / scrape** ← 日耳曼「刮」；**-ing** 标出动作正在进行，或把动词当名词用（the scraping of…）
- 真同源：
  - **scrape** — 刮；擦伤；勉强凑
  - **scrap** — 刮下来的碎片；废料；作废
  - **scraper** — 刮刀；抓取器
  - **scrapings** — 刮下来的那一层渣
- 形近勿混：
  - **scratch** — 用尖的东西划出细痕，是「划」，不是「贴着面刮下一层」
  - **scrub** — 来回用力擦洗，目的是洗干净，不是刮走一层带走
  - **grape** — 葡萄，只是长得有点像，不是亲戚
  - **crap** — 脏话/废物，另一条词源，不要靠谐音硬记成一家
- 构词提示：看见 **scrap-** 先问「是不是刮下来、剩下的薄层/边角」；**scratch / scrub** 动作相邻，但不是同一个刮法

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| scrape off | 刮掉 |
| scrape by | 勉强维持（钱刚够活） |
| scrape together | 东拼西凑；勉强凑齐 |
| scrape through | 勉强过关 |
| scrape your knee | 擦伤膝盖 |
| web scraping / data scraping | 网页抓取 / 数据抓取 |
| scrape the bottom of the barrel | 刮桶底；用到最差的那批 |
| bow and scrape | 点头哈腰（过分恭敬） |

## 5. 常用句子

### 句子 1
> She is scraping the ice off the windshield.

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| is scraping | 正在刮 |
| the ice | 冰 |
| off | 从……上离开 |
| the windshield | 挡风玻璃 |

**语法拆解**
- 句型：现在进行时 + off 标出被刮走的那一层
- 主干：She + is scraping + the ice
- 时态 / 语态：现在进行时（-ing 标出动作正在发生）
- 其他成分：off the windshield 标出冰原来贴在哪块表面上

### 句子 2
> They're scraping by on one income.

**逐词翻译**

| 词 | 意思 |
|----|------|
| They're | 他们正在 |
| scraping by | 勉强维持（把最后一点刮出来才够） |
| on | 靠 |
| one income | 一份收入 |

**语法拆解**
- 句型：主谓（短语动词）+ 方式状语
- 主干：They + are scraping by
- 时态 / 语态：现在进行时（日子一直紧）
- 其他成分：on one income 标出「从哪一层表面刮」——只有一份工资可刮

### 句子 3
> The team uses scraping to collect public prices from the site.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The team | 这个团队 |
| uses | 使用 |
| scraping | 抓取（把页面表层信息刮下来） |
| to collect | 为了收集 |
| public prices | 公开价格 |
| from the site | 从该网站 |

**语法拆解**
- 句型：主谓宾 + 目的状语
- 主干：The team + uses + scraping
- 时态 / 语态：一般现在时
- 其他成分：to collect… 表目的；scraping 在这里是动名词，当「这种刮法」用；public 标明刮的是公开信息，不是闯进去偷
