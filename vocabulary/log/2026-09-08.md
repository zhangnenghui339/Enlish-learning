今天问了 / 已入库：

- relentless（不懈 / 无情 / 持续不断；原子：lentus 软、可弯 → relent 软下来 → relentless 不软下来、不松手；同源 relent / lento；relevant、reluctant、restless 不是亲戚）
- illusion（错觉 / 假象 / 幻想；原子：ludere 玩、演戏 → illudere 对着感官玩一把；同源 delude / elude / allude / collude / prelude；allusion 是亲戚但方向不同，illustration 不是亲戚）
- hedonic（享乐的 / 快感型的；原子：希腊 hēdonē 那一口甜、爽 → 感官被取悦；同源 hedonism / anhedonia，更远同源 sweet / suave；hegemonic、harmonic 不是亲戚）
