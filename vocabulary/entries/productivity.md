# productivity

- **音标**：/ˌprɒdʌkˈtɪvəti/（美 /ˌprɑːdəkˈtɪvəti/）
- **词性**：n.
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **生产力；效率**（n.）— how much useful work is done in a given time
2. **产出能力**（n.）— the rate of producing goods, content, or results

## 2. 词根

- 词根 / 词缀：product（产品/成果）+ -ive（有……性质的）+ -ity（名词）→ 能产出成果的程度
- 构词提示：productive = 高效的；productivity = 生产力 / 做事效率

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| enhance / boost productivity | 提升生产力 |
| productivity tools | 效率工具 |
| team productivity | 团队效率 |
| lose productivity | 效率下降 |

## 4. 常用句子

### 句子 1
> The platform's integrations enhance productivity.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The platform's integrations | 该平台的集成能力 |
| enhance | 提升 |
| productivity | 生产力 / 效率 |

**语法拆解**
- 句型：主语 + 谓语 + 宾语
- 主干：integrations enhance productivity
- 时态 / 语态：一般现在时
