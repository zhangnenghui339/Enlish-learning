# archetype

- **音标**：/ˈɑːrkɪtaɪp/
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：arch- / arche-（原始的、最初的）+ type（类型、模型）
- 构词提示：最原始的那一型；同源 architecture、archaeology；对比 prototype（初版样品）、stereotype（刻板印象）

## 2. 高频常用意思

1. **原型；典型**（n.）— the original model that others of the same type are based on
2. **（品牌/角色）原型形象**（n.）— a classic character or brand pattern, e.g. hero archetype

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| an archetype of... | ……的原型 |
| brand archetype | 品牌原型 |
| hero archetype | 英雄原型 |
| fit an archetype | 符合某种原型 |
| challenge the archetype | 打破既有原型 |
| archetypal（adj.） | 典型的；原型式的 |

## 4. 常用句子

### 句子 1
> She is the archetype of a strong leader.

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| is | 是 |
| the | 这个 |
| archetype | 原型 |
| of | ……的 |
| a | 一个 |
| strong | 强大的 |
| leader | 领导者 |

**语法拆解**
- 句型：主系表
- 主干：She + is + the archetype
- 时态 / 语态：一般现在时
- 其他成分：of a strong leader 限定原型内容

### 句子 2
> This brand uses the rebel archetype in its marketing.

**逐词翻译**

| 词 | 意思 |
|----|------|
| This | 这个 |
| brand | 品牌 |
| uses | 使用 |
| the | 这个 |
| rebel | 反叛者 |
| archetype | 原型 |

| its | 它的 |

**语法拆解**
