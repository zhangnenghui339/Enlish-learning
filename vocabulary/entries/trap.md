# trap

- **音标**：/træp/
- **词性**：n. / v.
- **首次日期**：2026-08-15
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：中古英语 *trappe*（捕捉装置）；本义是「用来抓住的机关」
- 构词提示：实体「陷阱」→ 引申「圈套 / 困境」；动词 = 困住、诱捕  
  相关：**trapped**（被困住的）；**booby trap**（诡雷 / 整人装置）；习语 **fall into a trap**

## 2. 高频常用意思

1. **陷阱；圈套**（n.）— a device or plan used to catch or trick someone
2. **困境；让人难脱身的局面**（n.）— a bad situation that is hard to escape
3. **困住；诱捕；使陷入**（v.）— to catch, confine, or trick someone into a situation

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| fall / walk into a trap | 落入圈套 |
| set a trap | 设下陷阱 / 圈套 |
| trap sb into doing sth | 诱使某人做某事 |
| be trapped in / by… | 被困在……里 / 被……困住 |
| poverty / debt trap | 贫困陷阱 / 债务陷阱 |
| speed trap | （警察）测速点 |

## 4. 常用句子

### 句子 1
> Don't fall into the trap of chasing revenue before validation.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Don't | 不要 |
| fall into | 落入 |
| the trap | 这个陷阱 / 圈套 |
| of chasing | 追逐……的 |
| revenue | 营收 |
| before | 在……之前 |
| validation | 验证 |

**语法拆解**
- 句型：祈使句否定 + of 动名词短语
- 主干：Don't fall into the trap
- 时态 / 语态：祈使语气
- 其他成分：of chasing… 说明是哪种陷阱；呼应已学 revenue / validation

### 句子 2
> Freelancers can get trapped in an expensive, unprofitable workflow.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Freelancers | 自由职业者 |
| can get trapped | 可能被困住 |
| in | 在……里 |
| an expensive | 昂贵的 |
| unprofitable | 不赚钱的 |
| workflow | 工作流 |

**语法拆解**
- 句型：主语 + get trapped + 介词短语
- 主干：Freelancers + can get trapped
- 时态 / 语态：一般现在时；get trapped = 被动意味（陷入）
- 其他成分：in an… workflow 表困境所在；对照已学 profitable

### 句子 3
> The recruiter tried to trap him into accepting a low salary.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The recruiter | 招聘人员 |
| tried | 试图 |
| to trap him | 诱使他入套 |
| into accepting | 去接受 |
| a low salary | 一份低薪 |

**语法拆解**
- 句型：主语 + try to + 动词 + 宾语 + into doing
- 主干：The recruiter + tried to trap + him
- 时态 / 语态：一般过去时
- 其他成分：trap sb into doing = 诱使某人做某事；呼应已学 salary
