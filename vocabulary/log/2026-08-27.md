今天问了 / 已入库：

- upside（好处 / 上涨空间 / 朝上的一面；原子：up + side = 朝上那一面；对照 downside；短语 upside down）
- incremental（递增的 / 增量的 / 渐进的；原子：crescere 再长出一截；同源 increase / increment / crescent）
- wedge（楔子 / 挤进 / 一角蛋糕 / 挑拨离间；原子：一头厚一头尖，往缝里顶；短语 drive a wedge between）
- prime mover（推动者 / 原动机 / 第一推动者；原子：prime 第一 + mover 使动 = 链条最前端；勿混 first mover）
- 调整查找单词逻辑：对话开头补 **音标**；短语表改为 `短语 | 音标 | 意思`；例句加整句音标，逐词表加音标列（示范 `plane.md`）
