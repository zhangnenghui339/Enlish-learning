# Resume Checker

- **音标**：/rɪˈzjuːm ˈtʃekə/
- **词性**：n. phrase（产品功能名）
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **简历检查器**（n.）— a tool that reviews a resume for errors, formatting, or keyword fit
2. **resume**（美）/ **CV**（英）— 简历
3. **checker** — 检查器；核对工具

## 2. 词根

- 词根 / 词缀：
  - **resume** ← 法语 *résumé*（摘要）→ 履历摘要
  - **checker** = **check**（检查）+ **-er**（做某事的工具/人）
- 构词提示：检查 **resume（简历）** 的 **checker（检查器）**；常出现在 LinkedIn 上传场景

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| Resume Checker | 简历检查器 |
| check your resume | 检查你的简历 |
| ATS-friendly resume | 适合 ATS 的简历 |
| resume review | 简历审阅 |

## 4. 常用句子

### 句子 1
> Run your file through the Resume Checker before uploading to LinkedIn.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Run … through … | 把…放进…处理 |
| your file | 你的文件 |
| the Resume Checker | 简历检查器 |
| before uploading | 在上传之前 |
| to LinkedIn | 到 LinkedIn |

**语法拆解**
- 句型：祈使句 + before + 动名词
- 主干：(You) + run + file + through + Resume Checker
- 时态 / 语态：一般现在时（祈使）
- 其他成分：before uploading to LinkedIn 作时间状语

### 句子 2
> The Resume Checker flags missing keywords.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The Resume Checker | 简历检查器 |
| flags | 标记出；标红 |
| missing keywords | 缺失的关键词 |

**语法拆解**
- 句型：主谓宾
- 主干：Resume Checker + flags + keywords
- 时态 / 语态：一般现在时
- 其他成分：missing 作前置定语
