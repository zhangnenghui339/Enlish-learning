# command

- **音标**：/kəˈmɑːnd/（美 /kəˈmænd/）
- **词性**：n. / v.
- **首次日期**：2026-08-26
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **命令；指挥**（n. / v.）
   - 中文：发出必须照做的指令；掌管一支队伍或一项任务
   - 英文解释：to tell someone what they must do; to be the person in charge whose orders others follow
2. **掌握；精通**（n.）
   - 中文：一门技能被你握在手里，用起来听你的
   - 英文解释：having a skill or language firmly in your control, so you can use it when you need it
3. **（计算机）命令；指令**（n.）
   - 中文：敲给程序、让它立刻去做某事的那一行字
   - 英文解释：a typed or spoken instruction that tells a program exactly what to do

## 2. 原子意思

- **原子**：拉丁 *mandare* = **manus（手）+ dare（给）** → **交到某人手上**；加上 *com-* 加强 → **一旦交到你手上，就由你发令、由你掌控**
- **英文取词**：描述动作 —— **把控制权握在手里，再向外发出必须跟着走的指令**
- **中文取词**：描述看起来像哪一类东西 —— 对人叫**命令**，对技能叫**掌握**，对电脑叫**指令**
- **所以不是一词多义**：同一个「握在手里、由你发令」；中文才拆成命令、掌握、指令

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| command the troops | 把军队握在手里，向外发令 | 看起来是军务 → **指挥** |
| a command of English | 英语被你握在手里，用起来听你的 | 看起来是能力 → **掌握 / 精通** |
| run a command | 把一行字交到电脑手上，电脑必须照做 | 看起来是敲代码 → **命令 / 指令** |
| command respect | 你身上的力量强到别人必须把注意力交出来 | 看起来是赢得态度 → **博得尊敬** |
| the hill commands the valley | 这座山把山谷的视野握在手里 | 看起来是地势 → **俯瞰 / 控制** |

## 3. 词根

- 词根 / 词缀：**com-**（加强）+ **-mand-** ← 拉丁 *mandare*（交到手上、下令）← *manus*（手）+ *dare*（给）
- 真同源：
  - **mandate** — 正式交到手上的任务 / 授权
  - **mandatory** — 必须做的（已经交到你手上，不能不接）
  - **demand** — 用力要过来（像在下令要）
  - **commend / recommend** — 交到别人手上：托付、称赞、推荐
  - **remand** — 交回去（还押）
- 形近勿混：
  - **common** — 共同的，跟「手、下令」无关
  - **comment** — 评论，另一条词源
  - **commence** — 开始，跟 command 不是亲戚
- 构词提示：看见 **-mand- / -mend-** 先问「是不是交到手上、由此发令或托付」；能对上的才是亲戚

## 5. 常用句子

### 句子 1
> She took command of the project last week.

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| took command of | 接管了指挥权 |
| the project | 这个项目 |
| last week | 上周 |

**语法拆解**
- 句型：主谓宾 + 时间状语
- 主干：She + took command of + the project
- 时态 / 语态：一般过去时
- 其他成分：last week 表时间；took command of = 把控制权接到自己手上

### 句子 2
> He has a strong command of English.

**逐词翻译**

| 词 | 意思 |
|----|------|
| He | 他 |
| has | 有 |
| a strong command | 很强的掌控 |
| of English | 对英语的 |

**语法拆解**
- 句型：主谓宾
- 主干：He + has + a command
- 时态 / 语态：一般现在时
- 其他成分：of English 标明被握在手里的是哪门技能；strong 说掌控有多稳

### 句子 3
> Type the command and press Enter.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Type | 输入 |
| the command | 这条命令 |
| and | 然后 |
| press Enter | 按回车 |

**语法拆解**
- 句型：祈使句（两个并列动作）
- 主干：Type + the command；press + Enter
- 时态 / 语态：祈使语气
- 其他成分：and 连接先后两步；这里的 command 是交到电脑手上、必须照做的那一行
