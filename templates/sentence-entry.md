# 句子 / 段落解析模板

对话里按此结构回复；需要存档时保存为 `vocabulary/sentences/YYYY-MM-DD-<短标题>.md`。

```markdown
# 句子解析

## 双语对照（默认，必给）

English sentence one.
中文翻译一句。

English sentence two.
中文翻译一句。

（按原文逐句：一句英文，紧跟一句中文；列表/小标题同样处理）

## 补充（按需）

### 关键搭配
| 表达 | 意思 |
|------|------|
| … | … |

### 逐词翻译（单句或用户要求时）
| # | 词 / 短语 | 词性或作用 | 意思 |
|---|-----------|------------|------|
| 1 | … | … | … |

### 语法拆解（单句或难点句）
1. **句型**：…
2. **主干**：谁 + 做什么 + 什么
3. **时态 / 语态**：…
4. **修饰成分**：…
5. **难点**：…

## 已入库难词

（只列较复杂的词；已按单词模板写入 `entries/`）

- **word1** → `vocabulary/entries/word1.md`
- **word2** → …
```

**展示原则**：用户贴英文句子或段落时，对话回复**必须先**「一句英 + 一句中」，不要只给整段大意。  
**入库原则**：不要句中每个词都建条目；只收难词 / 多义词 / 习语核心词。
