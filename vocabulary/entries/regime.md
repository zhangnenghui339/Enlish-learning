# regime

- **音标**：/reɪˈʒiːm/（也可 /rɪˈʒiːm/）
- **词性**：n.
- **首次日期**：2026-09-01
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **政权；政体**（n.）
   - 中文：掌权的那一套人马和统治方式，常带一点「这个班子在管着」的口气
   - 英文解释：the government in power, especially when you are talking about how it rules, not just the country itself
2. **制度；管理体制**（n.）
   - 中文：把事情管在一条轨道上的那套规则
   - 英文解释：a system of rules for managing something — tax, safety, trade — that keeps it on a set path
3. **养生法；一套严格安排**（n.）
   - 中文：饮食、训练、用药被规定好的那条日程
   - 英文解释：a planned set of meals, workouts, or treatments that you stick to; overlaps with *regimen*

## 2. 原子意思

- **原子**：拉丁 *regere* = **把某物管在一条直线上、驾驭、统治** → *regimen / regime* = **用来驾驭的那套办法**
- **英文取词**：描述动作 —— **把人、国家或日常拉进一条既定轨道，不让它乱跑**
- **中文取词**：描述看起来像哪一类东西 —— 国家叫**政权**，规则叫**制度**，吃饭锻炼叫**养生法**
- **所以不是一词多义**：同一个「驾驭在一条轨道上」；中文才拆成政权、制度、养生

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| a military regime | 军队把国家**驾驭**在他们的轨道上 | 看起来是政治 → **军政府 / 政权** |
| a tax regime | 税收被**管在**一套规则里 | 看起来是制度 → **税制** |
| an exercise regime | 训练被**规定**成每天必须走的轨道 | 看起来是健身 → **训练计划 / 养生安排** |
| regime change | 换一套驾驭国家的班子 | 看起来是政变/更迭 → **政权更迭** |
| the old regime | 以前那套轨道（法 *ancien régime*） | 看起来是历史 → **旧制度** |

## 3. 词根

- 词根 / 词缀：**reg-** ← 拉丁 *regere*（驾驭、统治、保持直线）→ 法语 *régime* → **regime**
- 真同源：
  - **regimen** — 更偏饮食 / 疗程那条轨道（和 regime 近义，语体更「医嘱」）
  - **regular / regulate** — 拉回规则轨道
  - **regent** — 代为驾驭的人
  - **region** — 被统治的那片地
  - **regal / royal** — 王的
  - **regiment** — 被编成严格队列的部队；也可作「严管」
- 形近勿混：
  - **registry / register** — 来自 *gerere*（拿、带），是「写进名单」，**不是**「统治」
  - **regime** ≠ **regimen**：政治、制度多用 regime；食谱、疗程更常用 regimen（英式口语里 regime 也常说锻炼）
- 构词提示：看见 **reg-** 先问「是不是在驾驭、拉直」；能对上的才是亲戚

## 5. 常用句子

### 句子 1
> The military regime seized power in 1973.
>
> /ðə ˈmɪlətri reɪˈʒiːm siːzd ˈpaʊə ɪn ˈnaɪntiːn ˈseventi θriː/

**逐词翻译**

| 词 | 音标 | 意思 |
|----|------|------|
| The military regime | /ðə ˈmɪlətri reɪˈʒiːm/ | 这个军政府 |
| seized | /siːzd/ | 夺取了 |
| power | /ˈpaʊə/ | 权力 |
| in 1973 | /ɪn ˈnaɪntiːn ˈseventi θriː/ | 在 1973 年 |

**语法拆解**
- 句型：主谓宾 + 时间状语
- 主干：The military regime + seized + power
- 时态 / 语态：一般过去时
- 其他成分：military 标明谁在驾驭这条国家轨道

### 句子 2
> The new tax regime takes effect in January.
>
> /ðə njuː tæks reɪˈʒiːm teɪks ɪˈfekt ɪn ˈdʒænjuəri/

**逐词翻译**

| 词 | 音标 | 意思 |
|----|------|------|
| The new tax regime | /ðə njuː tæks reɪˈʒiːm/ | 新的税制 |
| takes effect | /teɪks ɪˈfekt/ | 生效 |
| in January | /ɪn ˈdʒænjuəri/ | 在一月 |

**语法拆解**
- 句型：主谓 + 时间状语
- 主干：The new tax regime + takes effect
- 时态 / 语态：一般现在时（时刻表 / 规定生效）
- 其他成分：tax regime = 把征税管在一条轨道上的那套规则

### 句子 3
> She stuck to a strict exercise regime for six months.
>
> /ʃi stʌk tu ə strɪkt ˈeksəsaɪz reɪˈʒiːm fə sɪks mʌnθs/

**逐词翻译**

| 词 | 音标 | 意思 |
|----|------|------|
| She | /ʃi/ | 她 |
| stuck to | /stʌk tu/ | 坚持了 |
| a strict exercise regime | /ə strɪkt ˈeksəsaɪz reɪˈʒiːm/ | 一套严格的训练安排 |
| for six months | /fə sɪks mʌnθs/ | 长达六个月 |

**语法拆解**
- 句型：主谓 + to 介词宾语 + 时间状语
- 主干：She + stuck to + a regime
- 时态 / 语态：一般过去时
- 其他成分：strict 强调这条日常轨道不许乱跑；这里的 regime ≈ regimen
