# sensor

- **音标**：/ˈsensər/
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁 *sentire / sens-*（感觉、感知）+ -or（……的装置）
- 构词提示：用来“感知”物理信号的装置；同源 sense、sensitive、sensation  
  易混：**censor**（审查员 / 审查）读音相近，意思完全不同

## 2. 高频常用意思

1. **传感器**（n.）— a device that detects light, heat, motion, pressure, etc. and sends a signal
2. **感应元件**（n.，语境）— the part that “feels” changes in the environment

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| motion / light sensor | 运动 / 光线传感器 |
| temperature sensor | 温度传感器 |
| sensor data | 传感器数据 |
| sensor network | 传感器网络 |
| trigger a sensor | 触发传感器 |

## 4. 常用句子

### 句子 1
> The motion sensor turns on the lights automatically.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The | 这个 |
| motion | 运动 |
| sensor | 传感器 |
| turns on | 打开 |
| the lights | 灯 |
| automatically | 自动地 |

**语法拆解**
- 句型：主谓宾 + 方式状语
- 主干：The motion sensor + turns on + the lights
- 时态 / 语态：一般现在时
- 其他成分：automatically 修饰 turns on

### 句子 2
> The car uses sensors to detect nearby objects.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The car | 汽车 |
| uses | 使用 |
| sensors | 传感器（复数） |
| to detect | 来检测 |
| nearby | 附近的 |
| objects | 物体 |

**语法拆解**
- 句型：主谓宾 + 目的状语
- 主干：The car + uses + sensors
- 时态 / 语态：一般现在时
- 其他成分：to detect… 表目的
