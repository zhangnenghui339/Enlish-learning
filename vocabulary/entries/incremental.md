# incremental

- **音标**：/ˌɪnkrəˈmentl/
- **词性**：adj.
- **首次日期**：2026-08-27
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **递增的；逐步增加的**（adj.）
   - 中文：不是一次到位，而是一小步一小步往上加
   - 英文解释：happening in small additions, step by step, rather than all at once
2. **增量的**（adj.）
   - 中文：只看「这次多出来的那一块」，不看总量
   - 英文解释：about the extra amount added this time — the new slice, not the whole pile
3. **渐进式的（改进）**（adj.）
   - 中文：靠连续的小改动往前推，不是推倒重来
   - 英文解释：improving by a series of small changes instead of one big leap or a complete redesign

## 2. 原子意思

- **原子**：拉丁 *incrementum* ← *increscere* = **in-（往上/往里）+ crescere（生长）** → **再长出一截；在原有的上面再加一点**
- **英文取词**：描述动作 —— **每次只多长一小截，而不是整棵突然变大**
- **中文取词**：描述看起来像哪一类东西 —— 过程叫**逐步增加**，多出来的那块叫**增量**，改产品叫**渐进改进**
- **所以不是一词多义**：同一个「再长出一截」；中文才拆成递增、增量、渐进

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| incremental growth | 规模一次只**再长一截** | 看起来是过程 → **逐步增长** |
| incremental cost | 每多做一件，**新长出来**的那笔成本 | 看起来是会计 → **增量成本** |
| incremental update | 软件只补上**新长出来**的那部分 | 看起来是发版 → **增量更新** |
| incremental improvement | 产品一次只**再好一点点** | 看起来是策略 → **渐进式改进** |
| increase | 同一条根：往上长 | 中文改口说**增加**（动词 / 总量），不再强调「一小截」 |

## 3. 词根

- 词根 / 词缀：**in-**（往里 / 往上）+ **-cresc- / -cre-**（生长）+ **-ment**（结果）+ **-al**（形容词）← 拉丁 *crescere*（生长）
- 真同源：
  - **increase** — 往上长 → 增加
  - **decrease** — 往下缩 → 减少
  - **increment** — 长出来的那一截 → 增量
  - **crescent** — 正在长大的月亮 → 新月 / 娥眉月
  - **crescendo** — 声音往上长 → 渐强
  - **accrue** — 贴着往上长 → 累积（利息等）
  - **concrete** — 长在一起变硬 → 混凝土；具体的
- 形近勿混：
  - **incredible** — *credere*（相信），跟「生长」无关
  - **incidental** — *cadere*（落下），碰巧发生，不是递增
  - **excrement** — 排出来的东西，不是 increment 的亲戚
- 构词提示：看见 **cresc- / cre- / crue-** 先问「是不是在生长、变大」；**incremental** 再加一层：每次只长一小截

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| incremental change | 渐进变化 |
| incremental improvement | 渐进式改进 |
| incremental cost | 增量成本 |
| incremental revenue | 增量收入 |
| incremental update | 增量更新 |
| incremental backup | 增量备份 |
| incremental learning | 增量学习；循序渐进地学 |
| on an incremental basis | 按增量 / 逐步进行 |
| incremental vs radical | 渐进 vs 激进 |

## 5. 常用句子

### 句子 1
> We made incremental improvements to the product.

**逐词翻译**

| 词 | 意思 |
|----|------|
| We | 我们 |
| made | 做了 |
| incremental improvements | 渐进式的改进 |
| to the product | 对这个产品 |

**语法拆解**
- 句型：主谓宾 + 介词短语
- 主干：We + made + improvements
- 时态 / 语态：一般过去时
- 其他成分：incremental 标明改进是「一次再长一小截」；to the product 标明改的对象

### 句子 2
> The incremental cost of each extra user is low.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The incremental cost | 增量成本 |
| of each extra user | 每多一个用户的 |
| is | 是 |
| low | 低的 |

**语法拆解**
- 句型：主系表
- 主干：The incremental cost + is + low
- 时态 / 语态：一般现在时
- 其他成分：of each extra user 标明「新长出来的那一截」对应谁；这里不看总成本，只看多一个人新加的成本

### 句子 3
> The company prefers incremental change over a complete redesign.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The company | 这家公司 |
| prefers | 更愿意选择 |
| incremental change | 渐进变化 |
| over | 而不是 |
| a complete redesign | 彻底重新设计 |

**语法拆解**
- 句型：主谓宾 + over 对比
- 主干：The company + prefers + incremental change
- 时态 / 语态：一般现在时
- 其他成分：over a complete redesign 把「一次再长一截」和「整棵拔掉重种」对照
