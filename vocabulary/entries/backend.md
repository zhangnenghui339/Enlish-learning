# backend

- **音标**：/ˈbækend/
- **词性**：n. / adj.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：back（后面）+ end（端）
- 构词提示：用户看不见的服务端——API、数据库、业务逻辑；对比 **frontend**  
  也写作 back-end；岗位：**Backend Engineer**

## 2. 高频常用意思

1. **后端**（n.）— the server-side part of an application
2. **后端的**（adj.）— related to APIs, databases, infrastructure

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| backend engineer / developer | 后端工程师 |
| backend API | 后端接口 |
| backend service | 后端服务 |
| frontend and backend | 前端和后端 |

## 4. 常用句子

### 句子 1
> The backend handles auth, payments, and data storage.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The backend | 后端 |
| handles | 处理 |
| auth | 认证 |
| payments | 支付 |
| and | 和 |
| data storage | 数据存储 |

**语法拆解**
- 句型：主谓宾
- 主干：The backend + handles + auth, payments, and data storage
- 时态 / 语态：一般现在时
- 其他成分：并列宾语说明职责范围
