# omnipotent narcissism

- **音标**：/ɒmˈnɪpətənt ˈnɑːsɪsɪzəm/（英）/ɑːmˈnɪpətənt ˈnɑːrsɪsɪzəm/（美）
- **拆读**：omnipotent（重音在 **nip**）+ narcissism（重音在 **nar**）
- **词性**：n. phrase（精神分析 / 人格心理）
- **首次日期**：2026-09-14
- **来源**：chat
- **掌握**：new
- **相关条目**：[`omnipotent.md`](omnipotent.md)、[`narcissism.md`](narcissism.md)

## 1. 高频常用意思

1. **全能自恋**（n.）
   - 中文：自恋里夹着「我无所不能」——世界该围着我转，别人不能限制我
   - 英文解释：a narcissistic stance that says “I am all-powerful”; the grandiose self treats the world as something it can control, and other people as mirrors or tools
2. **全能感式的自恋防御**（n.，心理）
   - 中文：用「我能搞定一切」挡住渺小、羞耻、无助
   - 英文解释：a defense: the fantasy of unlimited power covers over helplessness and shame; related to infantile omnipotence that never got limited by reality

## 2. 原子意思

- **原子**：把两条图景叠在一起 —— **力量没有外边**（omnipotent）+ **被自己的倒影吸住**（narcissism）→ 「我的倒影像神一样，能管住整个世界」
- **英文取词**：描述心理怎么动 —— 自我膨胀到没有边界，倒影要当宇宙中心
- **中文取词**：谈人格叫**全能自恋**，谈婴儿发展叫**全能感**，谈防御叫**全能控制**
- **所以不是一词多义**：同一个「倒影要当全能的神」；中文才按临床、发展和防御拆开说

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **omnipotent narcissism** | 自恋的倒影戴上「全能」王冠 | 人格/动力术语 → **全能自恋** |
| **infantile omnipotence** | 婴儿还分不清愿望和现实 | 发展术语 → **婴儿全能感** |
| **omnipotent control** | 用幻想或操控把别人按住 | 防御机制 → **全能控制** |
| **narcissistic rage** | 全能倒影被说「不」之后炸开 | 中文说**自恋暴怒**（全能一破就怒） |

不是「很能的自恋」这种字面加法，而是：**自恋靠全能幻想来维持**。

## 3. 词根

- 词根 / 词缀：**omni-**（全部）+ **pot-**（有力）+ **Narciss-**（那喀索斯 / 倒影）+ **-ism**（倾向）
- 真同源：见 `omnipotent.md`、`narcissism.md`（potent / possible；narcissist / Narcissus）
- 形近勿混：
  - 不要读成 *omnipotent* + *narcotics*（毒品）——narcissism 不是 narc
  - **grandiose narcissism**（夸大自恋）近义，但更强调「我很伟大」，不一定点出「我能控制一切」
- 构词提示：两个词都重；合在一起时想画面：**水仙看倒影，倒影却自称上帝**

## 5. 常用句子

### 句子 1
> Omnipotent narcissism treats other people as tools or mirrors.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Omnipotent narcissism | 全能自恋 |
| treats | 把……当作 |
| other people | 其他人 |
| as | 当作 |
| tools or mirrors | 工具或镜子 |

**语法拆解**
- 句型：主语 + treats + 宾语 + as 补足语
- 主干：Omnipotent narcissism + treats + other people + as tools or mirrors
- 时态 / 语态：一般现在时（定义这种心态）
- 其他成分：as tools or mirrors 点出别人没有独立位置——只为倒影和掌控服务

### 句子 2
> When reality limits him, his omnipotent narcissism turns into rage.

**逐词翻译**

| 词 | 意思 |
|----|------|
| When | 当 |
| reality | 现实 |
| limits him | 限制他 |
| his omnipotent narcissism | 他的全能自恋 |
| turns into | 变成 |
| rage | 暴怒 |

**语法拆解**
- 句型：when 时间从句 + 主句
- 主干：his omnipotent narcissism + turns into + rage
- 时态 / 语态：一般现在时（讲规律）
- 其他成分：When reality limits him 是触发条件——全能一碰到边界就碎，碎了就怒

### 句子 3
> Therapy often starts by naming the omnipotent narcissism without shaming it.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Therapy | 心理治疗 |
| often | 常常 |
| starts | 开始 |
| by naming | 通过点出 / 命名 |
| the omnipotent narcissism | 这种全能自恋 |
| without shaming it | 而不羞辱它 |

**语法拆解**
- 句型：主语 + 谓语 + by 方式状语 + without 伴随状语
- 主干：Therapy + starts
- 时态 / 语态：一般现在时
- 其他成分：by naming… 说明起步动作；without shaming it 说明态度——点破全能，但不砸倒影
