# separating

- **音标**：/ˈsepəreɪtɪŋ/
- **词性**：v.（separate 的现在分词 / 动名词；原形 separate 动词 /ˈsepəreɪt/，形容词 /ˈsepərət/）
- **首次日期**：2026-08-21
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **分开；把…拆开**（v.）
   - 中文：原来在一起的东西，正在被拉开、各放一边
   - 英文解释：the action of taking things that were together and putting space between them — they no longer sit as one pile
2. **分隔；隔开**（v.）
   - 中文：中间插进墙、线、距离，两边不再连通
   - 英文解释：to stand between two things as a barrier or gap, so one side cannot mix with the other
3. **分居；分手过程中**（v.）
   - 中文：两个人不再共同生活 / 感情上正在拆开
   - 英文解释：of a couple: no longer living or staying together as a pair; the relationship is being pulled apart, even if divorce is not finished
4. **区分**（v.）
   - 中文：在脑子里把两类东西划开，不当成一回事
   - 英文解释：to tell two kinds apart — keep facts on one side and opinions on the other, so they do not blur

## 2. 原子意思

- **原子**：拉丁 *separare* = **拉开、各放一边**（*se-* 往旁边 / 离开 + *parare* 安排、弄妥当）→ 把原来成堆的东西安排成「不再在一起」
- **英文取词**：描述动作 —— 往两边拽、中间留空，让它们不再粘成一团
- **中文取词**：描述看起来在拆哪一类对象 —— 拆物体叫**分开**，插屏障叫**分隔**，拆关系叫**分居 / 分手**，拆概念叫**区分**
- **所以不是一词多义**：同一个「拉开、各放一边」；中文才按对象拆成不同词

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **separating egg whites** | 蛋白和蛋黄原本在一起，正在被拉开 | 看起来是在「拆食材」→ **分开** |
| **a wall separating two rooms** | 墙站在中间，两边各放一边 | 看起来是在「挡开」→ **分隔** |
| **they're separating** | 两个人不再安排成一对 | 看起来是在「拆关系」→ **分居 / 分手** |
| **separating facts from opinions** | 把两类信息各放一边，不混 | 看起来是在「划界限」→ **区分** |
| **separate alerts**（形容词） | 告警被安排成各管各的，不合成一套 | 中文说**各自的 / 分开的** |

名词 **separation** = 拉开之后的状态或过程 → 中文叫**分离 / 分隔 / 分居**。  
形容词 **inseparable** = 拉不开 → 中文叫**形影不离的 / 密不可分的**。

动词 *separate* 重音在后面的长音 /eɪ/；形容词 *separate* 收成轻声 /ət/。同一拼写，动作还在拉开 vs 已经是分开的。

## 3. 词根

- 词根 / 词缀：**se-**（往旁边、离开）+ **par-** ← 拉丁 *parare*（安排、弄妥当）；**-ing** 标出动作正在进行，或把动词当名词用
- 真同源：
  - **separate / separation / separator** — 拉开；分离；分离器
  - **inseparable** — 拉不开
  - **several** — 原来也是「各是各的、分开的」，后来变成「若干、好几个」
  - **prepare / apparatus** — 同一条 *parare*（安排妥当）：预先安排 → 准备；安排好的一套 → 仪器 / 装置
  - **secede / secret / select** — 都带 *se-*（拉开、挑到一边），但后半截不是 *parare*
- 形近勿混：
  - **desperate** — *de-* + *sperare*（希望）→ 希望被抽走 → **绝望的**，跟「分开」无关
  - **disparate** — *dis-* + *par*（相等）→ 不相等、差很远 → **迥异的**；意思有点像「分开的两类」，但词根不是 separate
- 构词提示：看见 **se-** 先问「是不是拉开、弄到一边」；看见 **separate / several** 才是这一家。**desperate / disparate** 长得像，不是亲戚

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| separating A from B | 把 A 从 B 里分开 / 区分开 |
| they're separating | 他们在分居 / 分手 |
| a separating wall | 隔墙 |
| separate alerts | 各自独立的告警（形容词 separate） |
| go our separate ways | 各走各的路 |
| inseparable from | 与……密不可分 |
| legal separation | 合法分居 |
| oil–water separator | 油水分离器 |

## 5. 常用句子

### 句子 1
> She is separating the whites from the yolks.

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| is separating | 正在分开 |
| the whites | 蛋白 |
| from | 从……里 |
| the yolks | 蛋黄 |

**语法拆解**
- 句型：现在进行时 + from 引出被拉开的另一边
- 主干：She + is separating + the whites
- 时态 / 语态：现在进行时（-ing 标出动作正在发生）
- 其他成分：from the yolks 标出原来粘在一起、现在被各放一边的那一侧

### 句子 2
> A thin wall is separating the two rooms.

**逐词翻译**

| 词 | 意思 |
|----|------|
| A thin wall | 一堵薄墙 |
| is separating | 正在隔开 |
| the two rooms | 这两个房间 |

**语法拆解**
- 句型：主谓宾（进行时描写持续状态）
- 主干：A thin wall + is separating + the two rooms
- 时态 / 语态：现在进行时（墙持续站在中间）
- 其他成分：thin 修饰 wall；two 标出被拉开的两边

### 句子 3
> They're separating after ten years together.

**逐词翻译**

| 词 | 意思 |
|----|------|
| They're | 他们正在 |
| separating | 分居 / 分手（把一对拉开） |
| after | 在……之后 |
| ten years | 十年 |
| together | 在一起 |

**语法拆解**
- 句型：主谓 + 时间状语
- 主干：They + are separating
- 时态 / 语态：现在进行时（关系正在被拆开，不一定已经离完婚）
- 其他成分：after ten years together 对比：以前安排成一对，现在各放一边
