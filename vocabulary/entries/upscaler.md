# upscaler

- **音标**：/ˈʌpˌskeɪlər/
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：up-（向上）+ scale（比例、缩放）+ -er（……的工具/人）
- 构词提示：把图像/视频“放大到更高分辨率”的工具 → **upscaler**；动词 **upscale**（放大提升画质；也可作 adj. 高档的）

## 2. 高频常用意思

1. **放大增强工具 / 超分工具**（n.）— software or a model that increases image/video resolution and detail
2. **（泛指）提升规格的工具**（n.）— something that scales something up in quality or size

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| AI upscaler | AI 超分 / 放大工具 |
| image / video upscaler | 图像 / 视频放大器 |
| 2x / 4x upscaler | 两倍 / 四倍超分 |
| run through an upscaler | 用超分工具处理一遍 |
| upscale an image（v.） | 放大并增强一张图 |
