# cognitive

- **音标**：/ˈkɑːɡnətɪv/（美） /ˈkɒɡnətɪv/（英）
- **词性**：adj.
- **首次日期**：2026-08-20
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **认知的**（adj.）
   - 中文：跟「知道、理解、记住、推理」这些心智过程有关的
   - 英文解释：relating to the mind’s work of getting to know — thinking, remembering, attending, and making sense of things, as opposed to just feeling or moving
2. **思维 / 智力方面的**（adj.）
   - 中文：偏智力、思考能力这一侧，不是情绪、体力
   - 英文解释：about mental ability rather than emotion or the body — how well someone can process information, not how they feel
3. **认知科学 / 认知负荷里的「认知」**（adj.）
   - 中文：学术、产品、AI 语境里，指人脑处理信息的那一套机制
   - 英文解释：used as a label for the information-processing side of the mind (cognitive science, cognitive load, cognitive bias): how the knowing-system works, including where it glitches

## 2. 原子意思

- **原子**：拉丁 *cognoscere* = **去知道、把某物认下来**（*co-* 完全/一起 + *gnoscere / noscere* 知道）；形容词 *cognitivus* = **属于「去知道」这件事的**
- **英文取词**：描述心智**动起来**什么样 —— 在抓取、登记、串起来：看见 → 认出来 → 想通
- **中文取词**：描述它看起来是哪一类活动 —— 心里的「认」叫**认知**，能力侧叫**智力/思维**，科学标签叫**认知（科学）**
- **所以不是一词多义**：同一个「去知道」；中文才按场合拆成认知、思维、智力

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **cognitive process** | 心里「去知道」正在运转 | 看起来是一套心智工序 → **认知过程** |
| **cognitive ability** | 这套「去知道」做得好不好 | 看起来是智力测评 → **认知能力 / 思维能力** |
| **cognitive load** | 「去知道」一次塞太多，系统卡住 | 中文另起术语 → **认知负荷** |
| **cognitive bias** | 「去知道」走了捷径，认歪了 | 看起来是判断出错 → **认知偏差** |
| **recognize** | *re-* 再一次 + *cognoscere* 去知道 → 再次认下来 | 中文叫**认出 / 承认** |

名词 **cognition** = 那套「去知道」本身 → 中文叫**认知**。  
名词 **cognizance** / 形容词 **cognizant** = 已经把某事登记进「知道」里 → 中文叫**知晓 / 意识到**。

## 3. 词根

- 词根 / 词缀：**cogn- / gno- / gni-** ← 拉丁 *cognoscere*（去知道）；更深处是印欧 **\*gno-**（知道）。**-ive** = 属于……的、有……倾向的
- 真同源：
  - **cognition** — 认知（去知道这件事）
  - **cognizant** — 知晓的；意识到的
  - **recognize / recognition** — 再认一次 → 认出；承认
  - **incognito** — *in-* 不 + 被认出来 → 隐姓埋名
  - **ignorant / ignore** — *in-* 不 + *gnorare*（知道）→ 不知道；故意当不知道
  - **agnostic** — *a-* 不 + 希腊 *gnosis*（知识）→ 不可知论的（希腊这条也是同一个「知道」）
  - **diagnose** — 透过（*dia-*）去知道 → 诊断
- 形近勿混：
  - **cogent** — 有说服力的，来自拉丁 *cogere*（聚到一起、逼紧），**不是**「知道」
  - **cognac** — 干邑，法国地名，跟认知无关
  - **congenital** — 先天的，来自 *gen-*（生），不是 *gno-*（知）
- 构词提示：看见 **cogn- / gno- / gni-** 先问「是不是知道、认下来」；**cogent** 那条是「聚、逼」，别并成一家

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| cognitive process | 认知过程 |
| cognitive ability / skills | 认知能力；思维技能 |
| cognitive load | 认知负荷（脑子一次处理太多） |
| cognitive bias | 认知偏差 |
| cognitive science | 认知科学 |
| cognitive decline | 认知衰退 |
| cognitive behavioral therapy (CBT) | 认知行为疗法 |
| cognitive dissonance | 认知失调（两套「知道」互相打架） |

## 5. 常用句子

### 句子 1
> Sleep loss can slow down cognitive processes.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Sleep loss | 睡眠不足 |
| can | 可能 / 会 |
| slow down | 减慢 |
| cognitive processes | 认知过程（去知道的那套运转） |

**语法拆解**
- 句型：主谓宾（情态动词 + 动词短语）
- 主干：Sleep loss + can slow down + cognitive processes
- 时态 / 语态：一般现在时 + can（能力/可能性）
- 其他成分：cognitive 修饰 processes，标出被减慢的是「去知道」这一侧，不是手脚动作

### 句子 2
> The app tries to reduce cognitive load for new users.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The app | 这个应用 |
| tries to | 试图 |
| reduce | 减少 |
| cognitive load | 认知负荷 |
| for new users | 对新手用户来说 |

**语法拆解**
- 句型：主谓 + 不定式宾语 + 介词短语
- 主干：The app + tries + to reduce + cognitive load
- 时态 / 语态：一般现在时
- 其他成分：for new users 标明谁在「去知道」时负担过重

### 句子 3
> She is cognizant of the cognitive bias in her first draft.

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| is cognizant of | 意识到 / 知晓 |
| the cognitive bias | 这种认知偏差 |
| in her first draft | 在她的初稿里 |

**语法拆解**
- 句型：主系表 + of 宾语 + 地点状语
- 主干：She + is cognizant of + the cognitive bias
- 时态 / 语态：一般现在时
- 其他成分：cognizant 与 cognitive 同源：一个是「已经知道」，一个是「属于去知道的」；in her first draft 标出错在哪一份稿子
