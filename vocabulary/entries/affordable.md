# affordable

- **音标**：/əˈfɔːrdəbl/
- **词性**：adj.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：afford（负担得起）+ -able（能够……的）
- 构词提示：价格上“买得起 / 用得起”；常对比昂贵方案（如 $79–$300/mo）

## 2. 高频常用意思

1. **负担得起的；价格合理的**（adj.）— not too expensive；priced so people can pay for it
2. **（对某群体）可承受的**（adj.）— affordable for freelancers / small teams

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| affordable solution | 价格可承受的方案 |
| affordable price | 实惠价格 |
| more affordable than... | 比……更便宜 |
| make... affordable | 使……变得可负担 |

## 4. 常用句子

### 句子 1
> No affordable solution fills the cross-platform gap.

**逐词翻译**

| 词 | 意思 |
|----|------|
| No | 没有 |
| affordable | 可负担的 |
| solution | 方案 |
| fills | 填补 |
| the cross-platform gap | 跨平台空白 |

**语法拆解**
- 句型：主谓宾
- 主干：No affordable solution + fills + the gap
- 时态 / 语态：一般现在时
- 其他成分：强调“不是没人看到空白，而是缺便宜方案”
