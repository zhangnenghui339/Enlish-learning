# proposal

- **音标**：/prəˈpəʊzl/
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：pro-（向前）+ pose（放置）→ propose（提出）→ proposal（提出的方案）
- 构词提示：在自由职业平台上，proposal ≈ 对某个 job post 提交的**提案 / 竞标申请**

## 2. 高频常用意思

1. **提案；建议书**（n.）— a formal plan or offer
2. **（接单平台）投标申请**（n.）— a freelance application for a job post

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| send / submit a proposal | 提交提案 |
| job proposal | 接单提案 |
| 50 proposals flooding... | 五十份提案涌入…… |
| proposal writing | 写提案 |

## 4. 常用句子

### 句子 1
> Over 50 proposals flood job posts in 24 hours.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Over 50 | 超过五十份 |
| proposals | 提案 |
| flood | 涌入 |
| job posts | 职位帖子 |
| in 24 hours | 在二十四小时内 |

**语法拆解**
- 句型：主谓宾 + 时间状语
- 主干：proposals + flood + job posts
- 时态 / 语态：一般现在时（表常态）
- 其他成分：flood 形象表示“挤爆”
