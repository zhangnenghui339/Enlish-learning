# frontend

- **音标**：/ˈfrʌntend/
- **词性**：n. / adj.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：front（前面）+ end（端）
- 构词提示：用户直接看到、点到的那一端；对比 **backend**（背后的服务端）  
  也写作 front-end / front end；岗位：**Frontend Engineer / Developer**

## 2. 高频常用意思

1. **前端**（n.）— the part of an app users see and interact with (UI)
2. **前端的**（adj.）— related to UI/client-side work；frontend role

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| frontend engineer / developer | 前端工程师 |
| frontend tech stack | 前端技术栈 |
| frontend vs backend | 前端 vs 后端 |
| frontend framework | 前端框架（React 等） |

## 4. 常用句子

### 句子 1
> We're hiring a frontend engineer for a remote role.

**逐词翻译**

| 词 | 意思 |
|----|------|
| We're hiring | 我们正在招聘 |
| a frontend engineer | 一位前端工程师 |
| for | 为了 |
| a remote role | 一个远程岗位 |

**语法拆解**
- 句型：主谓宾 + 目的状语
- 主干：We + are hiring + a frontend engineer
- 时态 / 语态：现在进行时
- 其他成分：for a remote role 表岗位类型
