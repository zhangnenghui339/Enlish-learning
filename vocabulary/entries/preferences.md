# preferences

- **音标**：/ˈprefərənsɪz/（单数 preference /ˈprefərəns/）
- **词性**：n. (often plural)
- **首次日期**：2026-08-26
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **偏好；喜好**（n.）
   - 中文：更喜欢哪一边；把某选项放在前面
   - 英文解释：what you put first among choices; the thing you would rather have than the rest
2. **偏好设置**（n. pl.）
   - 中文：软件里记下「你希望它怎么工作」的那一组选项
   - 英文解释：the settings that store how you want a program to behave — language, theme, notifications, defaults
3. **优先；优待**（n.）
   - 中文：把某人/某事排到别人前面；优先处理
   - 英文解释：treating one person or option as coming before others; giving it first place

## 2. 原子意思

- **原子**：拉丁 *praeferre* = **prae-（在前）+ ferre（拿、扛）** → **把某物先拿起来、放到前面**
- **英文取词**：描述动作 —— 在一堆选项里，**先举起这一件**
- **中文取词**：描述看起来像哪一类东西 —— 口味上叫**偏好**，软件里叫**设置**，排队时叫**优先**
- **所以不是一词多义**：同一个「放到前面」；中文才拆成喜好、设置、优待

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| a preference for tea | 在茶和咖啡之间，把茶**放到前面** | 看起来是口味 → **偏好 / 更爱喝茶** |
| System Preferences | 把你希望系统怎么工作的选项**先记下来** | 看起来是一堆开关 → **系统偏好设置** |
| give preference to seniors | 把老年人**排到队伍前面** | 看起来是待遇 → **优先照顾** |
| preferred stock | 分红时把这类股票**放到普通股前面** | 看起来是金融品种 → **优先股** |

## 3. 词根

- 词根 / 词缀：**pre-**（在前）+ **-fer-**（拿、带）+ **-ence**（名词）← 拉丁 *praeferre*
- 真同源（都是 *ferre*「拿、带」长出来的）：
  - **prefer / preferred** — 更喜欢；优先的（先拿这一件）
  - **confer** — 一起拿来商量 → 商讨；授予
  - **refer** — 拿回去指向某处 → 参考；转介
  - **transfer** — 拿到另一边 → 转移
  - **offer** — 朝对方拿过去 → 提供
  - **differ** — 拿到两边分开 → 不同
- 形近勿混：
  - **reference** — 同源（refer），但是「指向某处」不是「放到前面」
  - **presence** — *prae-* + *esse*（在），「在场」，不是「拿」
  - **inference** — *in-* + *ferre*，从证据里「拿出来」的结论，不是偏好
- 构词提示：看见 **-fer- / -lat-**（*ferre* 的过去分词 *latus*）先问「是不是在搬、拿、带」；**pre-** 再问「是不是放到前面」

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| a preference for | 对……的偏好 |
| personal preferences | 个人偏好 |
| user preferences | 用户偏好 / 用户设置 |
| system preferences | 系统偏好设置 |
| in order of preference | 按偏好顺序 |
| give preference to | 优先考虑 / 优待 |
| have no preference | 没有偏好；都行 |
| dietary preferences | 饮食偏好 |

## 5. 常用句子

### 句子 1
> Do you have a preference for tea or coffee?

**逐词翻译**

| 词 | 意思 |
|----|------|
| Do you have | 你有没有 |
| a preference | 一种偏好 |
| for | 对于 |
| tea or coffee | 茶还是咖啡 |

**语法拆解**
- 句型：一般疑问句（Do + 主语 + 动词）
- 主干：you + have + a preference
- 时态 / 语态：一般现在时
- 其他成分：for tea or coffee 标明在哪两样里「把哪样放到前面」

### 句子 2
> Open System Preferences and turn off notifications.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Open | 打开 |
| System Preferences | 系统偏好设置 |
| and | 然后 |
| turn off | 关掉 |
| notifications | 通知 |

**语法拆解**
- 句型：祈使句（两个并列动作）
- 主干：Open + System Preferences；turn off + notifications
- 时态 / 语态：祈使语气
- 其他成分：and 连接先后两步；这里的 Preferences 是「先记下你怎么用系统」的那一页

### 句子 3
> The hiring team gave preference to candidates with remote experience.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The hiring team | 招聘团队 |
| gave preference to | 把……放到前面 / 优先考虑 |
| candidates | 候选人 |
| with remote experience | 有远程工作经验的 |

**语法拆解**
- 句型：主谓宾 + 后置定语
- 主干：The hiring team + gave preference to + candidates
- 时态 / 语态：一般过去时
- 其他成分：with remote experience 修饰 candidates，说明哪一类人被「排到前面」
