# velocity

- **音标**：/vəˈlɒsəti/（BrE）; /vəˈlɑːsəti/（AmE）
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁语 *velox / veloc-*（快的）+ *-ity*（名词后缀：性质/状态）
- 构词提示：veloc- = 快 → velocity = 速度；同源 *velociraptor*（迅龙）。  
  商业里常不等于单纯 “speed”，更强调**变化有多快**（如 trend velocity）

## 2. 高频常用意思

1. **速度**（n.，物理/正式）— the speed of something in a given direction
2. **（变化/增长的）速率**（n.，商业引申）— how fast something is changing or growing

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| trend velocity | 趋势速度（趋势扩散/升温有多快） |
| high / low velocity | 高 / 低速率 |
| growth velocity | 增长速率 |
| at high velocity | 以高速 |
| increase in velocity | 速度加快 |

## 4. 常用句子

### 句子 1
> The trend velocity of Pilates has accelerated this year.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The | 这个 |
| trend | 趋势 |
| velocity | 速度 |
| of | ……的 |
| Pilates | 普拉提 |
| has accelerated | 已经加速 |
| this year | 今年 |

**语法拆解**
- 句型：主语 + 谓语 + 时间状语
- 主干：The trend velocity + has accelerated
- 时态 / 语态：现在完成时
- 其他成分：of Pilates 限定是哪条趋势；this year 表时间

### 句子 2
> High velocity does not always mean lasting demand.

**逐词翻译**

| 词 | 意思 |
|----|------|
| High | 高的 |
| velocity | 速度 |
| does not | 并不 |
| always | 总是 |
| mean | 意味着 |
| lasting | 持久的 |
| demand | 需求 |

**语法拆解**
- 句型：主语 + 谓语 + 宾语
- 主干：High velocity + does not mean + lasting demand
- 时态 / 语态：一般现在时（否定）
- 其他成分：always 修饰 mean；lasting 修饰 demand
