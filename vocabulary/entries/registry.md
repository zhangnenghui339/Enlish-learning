# registry

- **音标**：/ˈredʒɪstri/
- **词性**：n.
- **首次日期**：2026-08-28
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **登记处；注册处**（n.）
   - 中文：把名字、所有权、婚姻等正式写进去的那个机构或系统
   - 英文解释：the office or system where names and official facts are written down and kept, so they can be looked up later
2. **登记簿；名册**（n.）
   - 中文：那本被写进去的册子 / 那份正式名单
   - 英文解释：the book or list itself — the official record that holds those names
3. **注册表；礼品登记**（n.）
   - 中文：电脑里集中存放设置的那份「官方名单」（Windows Registry）；婚礼上客人按名单买礼物的清单
   - 英文解释：a stored list of settings (the Windows Registry) or of wanted gifts (a wedding registry) — still an official place where items are written back in

## 2. 原子意思

- **原子**：拉丁 *regerere* = **re-（回去）+ gerere（拿、带）** → **把信息带回去，写进一份正式保存的名单**
- **英文取词**：描述动作 —— **写回去、存进官方那一本，以后还能查**
- **中文取词**：描述看起来像哪一类东西 —— 地方叫**登记处**，本子叫**名册**，电脑叫**注册表**，婚礼叫**礼品登记**
- **所以不是一词多义**：同一个「写进官方名单」；中文才拆成登记处、名册、注册表

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| land registry | 土地所有权被**写回**官方系统 | 看起来是机构 → **土地登记处** |
| a registry of companies | 公司名被**写进**那本名册 | 看起来是名册 → **公司登记簿** |
| Windows Registry | 系统设置被**写回**一份集中名单 | 看起来是电脑配置 → **注册表** |
| wedding registry | 想要的礼物被**写进**一份给客人看的名单 | 看起来是婚礼清单 → **礼品登记** |
| registry office | 结婚/出生必须去**写进官方记录**的那间办公室 | 英式说法 → **注册处 / 登记处** |

## 3. 词根

- 词根 / 词缀：**re-**（回去）+ **-ger- / -gist-**（拿、带）+ **-ry**（地点 / 集合）← 拉丁 *regerere* → *registrum* → **register / registry**
- 真同源（都从 *gerere*「拿、带」长出来）：
  - **register** — 登记；寄存器（把信息写进去）
  - **registrar** — 管这份名单的人
  - **registration** — 写进去这个动作
  - **gesture** — 把意思用手带出来
  - **suggest / digest** — 把想法递过去 / 把食物带下去分解
- 形近勿混（看起来像「管、王」，其实是另一条 *regere*「统治」）：
  - **region / regular / regiment / regal** — 跟「写进名单」无关
  - **registry** ≠ **registrar**：一个是地方/名册，一个是人
- 构词提示：看见 **regist-** 先问「是不是写回官方名单」；看见 **reg-** 再问「是 gerere 拿，还是 regere 统治」，别混成一家

## 5. 常用句子

### 句子 1
> Check the land registry before you buy the house.
>
> /tʃek ðə lænd ˈredʒɪstri bɪˈfɔː ju baɪ ðə haʊs/

**逐词翻译**

| 词 | 音标 | 意思 |
|----|------|------|
| Check | /tʃek/ | 查一下 |
| the land registry | /ðə lænd ˈredʒɪstri/ | 土地登记处 |
| before | /bɪˈfɔː/ | 在……之前 |
| you buy the house | /ju baɪ ðə haʊs/ | 你买这栋房子 |

**语法拆解**
- 句型：祈使句 + before 时间从句
- 主干：Check + the land registry
- 时态 / 语态：祈使语气
- 其他成分：before you buy the house 标明为什么要去查那份官方名单

### 句子 2
> Don't edit the Windows Registry unless you know what you are doing.
>
> /dəʊnt ˈedɪt ðə ˈwɪndəʊz ˈredʒɪstri ənˈles ju nəʊ wɒt ju ə ˈduːɪŋ/

**逐词翻译**

| 词 | 音标 | 意思 |
|----|------|------|
| Don't | /dəʊnt/ | 不要 |
| edit | /ˈedɪt/ | 改 |
| the Windows Registry | /ðə ˈwɪndəʊz ˈredʒɪstri/ | Windows 注册表 |
| unless | /ənˈles/ | 除非 |
| you know | /ju nəʊ/ | 你知道 |
| what you are doing | /wɒt ju ə ˈduːɪŋ/ | 你在做什么 |

**语法拆解**
- 句型：否定祈使句 + unless 条件从句
- 主干：Don't edit + the Windows Registry
- 时态 / 语态：祈使语气；从句现在进行时
- 其他成分：unless… 限制「别去改这份官方设置名单」的例外

### 句子 3
> They registered at a registry office, not a church.
>
> /ðeɪ ˈredʒɪstəd ət ə ˈredʒɪstri ˈɒfɪs nɒt ə tʃɜːtʃ/

**逐词翻译**

| 词 | 音标 | 意思 |
|----|------|------|
| They | /ðeɪ/ | 他们 |
| registered | /ˈredʒɪstəd/ | 登记结婚了 |
| at a registry office | /ət ə ˈredʒɪstri ˈɒfɪs/ | 在登记处 |
| not | /nɒt/ | 而不是 |
| a church | /ə tʃɜːtʃ/ | 教堂 |

**语法拆解**
- 句型：主谓 + 地点状语 + 对比
- 主干：They + registered
- 时态 / 语态：一般过去时
- 其他成分：at a registry office 是把婚姻写进官方记录的地方；registered 是动作，registry 是地方，不要混
