# agency simulation

- **音标**：/ˈeɪdʒənsi ˌsɪmjuˈleɪʃn/
- **拆读**：agency（重音在 **a**）+ simulation（重音在 **la**）
- **词性**：n. phrase（哲学 / 心理 / AI）
- **首次日期**：2026-09-14
- **来源**：chat
- **掌握**：new
- **相关条目**：[`agency.md`](agency.md)、[`simulation.md`](simulation.md)

## 1. 高频常用意思

1. **能动性模拟**（n.）
   - 中文：把「能自己起意、自己做事」这件事做成一个像，而不是真的拥有它
   - 英文解释：a working likeness of agency — a system, character, or exercise that *looks* like it can choose and act, without that proving it is a real agent
2. **主体性仿真**（n.，AI / 认知）
   - 中文：让模型或角色表现出目标、选择、行动，像有一只手在推
   - 英文解释：modeling or displaying goal-directed action so observers read “someone is doing this”; common in AI, games, and social-cognition research
3. **（少见另一读）代理公司做的模拟**（n.）
   - 中文：一家 agency 去跑 simulation（广告公司、咨询公司做推演）
   - 英文解释：a simulation run *by* an agency; only this reading if context is business, not mind or machines

## 2. 原子意思

- **原子**：两条图景叠在一起 —— **有一只手在推**（agency）+ **做成像**（simulation）→ 「把『能做』做得像真的那样转」
- **英文取词**：描述它动起来 —— 外面像有主体在选、在做；里面可能只是程序、角色、练习
- **中文取词**：谈 AI/心理叫**能动性模拟 / 主体性仿真**；谈公司业务才叫**代理公司的模拟**
- **所以不是一词多义**：同一个「把能做做成像」；中文才按场合拆开说

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **agency simulation in a chatbot** | 对话像有目标、有选择 | **能动性模拟**（看起来会做事） |
| **simulated agency vs real agency** | 像在做 vs 真的能做主 | 中文用**仿真主体**对照**真正能动性** |
| **sense of agency in VR** | 虚拟里也觉得「是我在推」 | **（虚拟中的）主体感**——偏体验，不一定是整套仿真 |
| **the agency's simulation** | 公司在跑推演 | 所有格才是**这家代理公司的模拟** |

关键对照：simulation 给的是**像**；agency 要的是**真能做**。合在一起，常常是在问：这只是像有手，还是真有手？

## 3. 词根

- 词根 / 词缀：**ag-**（做、驱）+ **-ency** + **simul-**（像）+ **-ation**
- 真同源：见 `agency.md`、`simulation.md`（act / agent；similar / simulate）
- 形近勿混：
  - 不要先看成 **ad agency**（广告公司）+ simulation，除非上下文是商业
  - **stimulation** — 刺激，不是 simulation
  - **agenda simulation** — 不是固定短语；agenda 是「待办清单」，别和 agency 混
- 构词提示：先拆成 **agency（能做）** + **simulation（做成像）**；问一句「像有主体，还是真有主体？」

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| agency simulation | 能动性模拟 |
| simulated agency | 被模拟出来的能动性 |
| real vs simulated agency | 真正的能动性 vs 装出来的 |
| sense of agency | 主体感（我觉得是我在做） |
| apparent agency | 表面上的能动性 |
| goal-directed simulation | 有目标导向的仿真 |

## 5. 常用句子

### 句子 1
> Agency simulation can fool us into reading intention where there is only pattern.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Agency simulation | 能动性模拟 |
| can fool us | 能骗过我们 |
| into reading intention | 以至于读出「意图」 |
| where | 在……之处 |
| there is only pattern | 其实只有模式 |

**语法拆解**
- 句型：主语 + can + 动词 + into 结果 + where 从句
- 主干：Agency simulation + can fool + us
- 时态 / 语态：一般现在时（能力 / 规律）
- 其他成分：into reading… 是 fool 的结果；where 从句把「像有手」和「只有花纹」拆开

### 句子 2
> The game uses agency simulation so NPCs look like they choose.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The game | 这个游戏 |
| uses | 使用 |
| agency simulation | 能动性模拟 |
| so | 以便 |
| NPCs | 非玩家角色 |
| look like they choose | 看起来像在做选择 |

**语法拆解**
- 句型：主谓宾 + so 目的/结果从句
- 主干：The game + uses + agency simulation
- 时态 / 语态：一般现在时
- 其他成分：look like they choose 点出原子「做成像」——像在选，不等于真在选

### 句子 3
> Don't confuse a sense of agency with agency simulation in the model.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Don't confuse | 不要把……混淆 |
| a sense of agency | 主体感 |
| with | 和 |
| agency simulation | 能动性模拟 |
| in the model | 在这个模型里的 |

**语法拆解**
- 句型：祈使句；confuse A with B
- 主干：Don't confuse + A + with + B
- 时态 / 语态：祈使语气
- 其他成分：人这边的「我觉得我在做」≠ 模型那边「把能做做得像」
