# ATS

- **音标**：/ˌeɪ tiː ˈes/
- **词性**：n. (abbr.)
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：缩写 = **A**pplicant **T**racking **S**ystem（应聘者追踪系统）
- 构词提示：公司用来收简历、筛选、推进面试流程的软件；简历常需 “ATS-friendly”

## 2. 高频常用意思

1. **应聘者追踪系统**（n.）— software that collects and filters job applications
2. **（求职语境）简历筛选系统**（n.）— the system that may reject resumes before a human sees them

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| ATS-friendly resume | 适合 ATS 解析的简历 |
| pass the ATS | 通过 ATS 筛选 |
| ATS keywords | ATS 关键词 |
| ATS software | ATS 软件 |

## 4. 常用句子

### 句子 1
> Many resumes never pass the ATS.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Many resumes | 许多简历 |
| never | 从不 |
| pass | 通过 |
| the ATS | ATS 系统 |

**语法拆解**
- 句型：主谓宾
- 主干：Many resumes + pass + the ATS
- 时态 / 语态：一般现在时（否定：never）
- 其他成分：never 表完全否定频率

### 句子 2
> Use keywords so your resume is ATS-friendly.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Use | 使用 |
| keywords | 关键词 |
| so | 以便 |
| your resume | 你的简历 |
| is | 是 |
| ATS-friendly | 对 ATS 友好的 |

**语法拆解**
- 句型：祈使句 + so 结果从句
- 主干：Use keywords / your resume is ATS-friendly
- 时态 / 语态：祈使 + 一般现在时
- 其他成分：so 表目的/结果
