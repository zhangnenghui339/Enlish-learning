# Lebensraum

- **音标**：/ˈleɪbənzraʊm/
- **词性**：n.（德语借词；英语里常大写，作历史专名）
- **首次日期**：2026-08-19
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **生存空间**（n.，纳粹扩张口号）
   - 中文：纳粹德国声称本民族「不够住、不够活」，必须向外夺地——尤其向东扩张
   - 英文解释：in English, almost always the Nazi claim that a people must seize more territory in order to live and grow; it was used to justify conquest, expulsion, and mass killing in Eastern Europe
2. **（字面）活着所占的空间**（n.，德语普通义）
   - 中文：生物或人过日子需要的那块空间；栖息地
   - 英文解释：in ordinary German, the space a living thing occupies or needs — close to habitat / living room in the literal sense. English almost never uses Lebensraum this way

英语阅读里遇到这个词，默认按义项 1 理解，不要当成中性的「住房/空间」。

## 2. 原子意思

- **原子**：德语 **Leben**（生命、活着）+ **Raum**（空间、房间）→ **活着所占的那块空间**
- **英文取词**：描述性状 —— 一块给生命展开的空间
- **中文取词**：中性场合叫**生存空间 / 栖息地**；20 世纪被纳粹拿去当口号后，看起来就像**侵略借口**
- **所以不是一词多义**：空间还是那块「给生命用的地方」；变的是谁有权住、谁必须被挤走。中文才需要另标「纳粹口号」

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **Lebensraum**（德语日常） | 一只动物、一户人家**活下去需要的空间** | 看起来是地理/生态词 → **生存空间；栖息地** |
| **Nazi Lebensraum** | 把「我们要活」说成「别人的地必须腾给我们」 | 看起来是侵略理论 → **生存空间（扩张口号）** |
| **living space**（英语直译） | 同一原子的英语说法 | 中性时是**居住空间**；一谈纳粹政策，仍译**生存空间** |
| **habitat** | 也是生命所占的空间，但是生态学术语 | 中文用**栖息地**，不借用这个德语词 |

历史注意：这个词本身不是「屠杀」的同义词，但纳粹用它为东线征服、驱逐和种族灭绝提供借口。学它是为了读懂历史文本，不是为了沿用那套说法。

## 3. 词根

- 词根 / 词缀：德语复合词 **Leben-s-Raum**
  - **Leben** = 生命、生活 ← 日耳曼语，和英语 **life / live** 同源
  - **-s-** = 德语属格连接（Leben 的 Raum）
  - **Raum** = 空间、房间 ← 和英语 **room** 同源
- 真同源：
  - **life / live / alive** — 生命；活着
  - **room** — 房间；空间
  - **Lebenslauf** — 履历（生命走过的路程）
  - **Wohnraum** — 住房面积（住的空间）
- 形近勿混：
  - **Lebensborn** — 纳粹另一套生育计划的名字，不是「空间」
  - **Renaissance** — 文艺复兴，拉丁「再出生」，不是德语 Raum
  - **habitat** — 栖息地，拉丁 *habitare*（居住），意思近、词源不是一家
- 构词提示：德语常把两个名词直接粘在一起。看见 **Leben + Raum**，先拆成「生命的空间」；在英语历史书里再叠上纳粹用法

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| Nazi Lebensraum | 纳粹的「生存空间」政策 |
| Lebensraum in the East | 向东方夺取生存空间 |
| the quest for Lebensraum | 对生存空间的追求（史学术语） |
| living space | 字面英译：居住/生存空间 |
| a pretext of Lebensraum | 以生存空间为借口 |

## 5. 常用句子

### 句子 1
> The Nazis used Lebensraum as a pretext for invading Eastern Europe.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The Nazis | 纳粹 |
| used | 把……当作；使用 |
| Lebensraum | 「生存空间」这套说法 |
| as a pretext | 当作借口 |
| for invading | 来为侵略……辩护 |
| Eastern Europe | 东欧 |

**语法拆解**
- 句型：主谓宾 + as 补足语 + for 介词短语
- 主干：The Nazis + used + Lebensraum
- 时态 / 语态：一般过去时
- 其他成分：as a pretext 标明用法是借口；for invading… 表这个借口要干的事

### 句子 2
> In German, Lebensraum can simply mean the space a living thing needs.

**逐词翻译**

| 词 | 意思 |
|----|------|
| In German | 在德语里 |
| Lebensraum | 这个词 |
| can simply mean | 也可以只表示 |
| the space | 那块空间 |
| a living thing needs | 一个生物所需要的 |

**语法拆解**
- 句型：主谓宾 + 定语从句
- 主干：Lebensraum + can mean + the space
- 时态 / 语态：一般现在时（讲词义）
- 其他成分：In German 限定语言；a living thing needs 修饰 space；simply 强调「原本很普通」

### 句子 3
> Historians discuss Lebensraum when they explain Nazi expansion.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Historians | 历史学家 |
| discuss | 讨论 |
| Lebensraum | 「生存空间」概念 |
| when | 当……的时候 |
| they explain | 他们解释 |
| Nazi expansion | 纳粹的扩张 |

**语法拆解**
- 句型：主谓宾 + when 时间从句
- 主干：Historians + discuss + Lebensraum
- 时态 / 语态：一般现在时（学科习惯）
- 其他成分：when they explain Nazi expansion 标出这个词出现的语境——解释侵略，而不是日常住房
