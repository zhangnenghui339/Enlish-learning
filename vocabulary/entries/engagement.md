# engagement

- **音标**：/ɪnˈɡeɪdʒmənt/
- **词性**：n.
- **首次日期**：2026-08-15
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：动词 **engage**（吸引；参与；聘用）+ **-ment**（名词）
- 构词提示：被「拉进来参与」→ **参与度；互动；约定**  
  相关：**engage with**（与……互动）；**engaging**（吸引人的）；产品语境常与 **retention** 成对出现

## 2. 高频常用意思

1. **（用户）参与度；互动**（n.）— how actively users click, post, open, or use a product
2. **约定；约会；日程安排**（n.）— an arrangement to meet or do something at a time
3. **订婚**（n.）— an agreement to get married（生活语境）

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| user / customer engagement | 用户 / 客户参与度 |
| engagement rate | 互动率；参与率 |
| boost / drive engagement | 提升互动 / 参与 |
| prior engagement | 已有安排（常作婉拒理由） |
| engagement metrics | 参与度指标 |

## 4. 常用句子

### 句子 1
> High engagement often comes before strong retention.

**逐词翻译**

| 词 | 意思 |
|----|------|
| High engagement | 高参与度 |
| often | 常常 |
| comes | 出现 |
| before | 在……之前 |
| strong retention | 强留存 |

**语法拆解**
- 句型：主语 + 谓语 + 时间状语
- 主干：High engagement + comes
- 时态 / 语态：一般现在时（表规律）
- 其他成分：先有互动，再谈留存；呼应已学 retention

### 句子 2
> The dashboard shows engagement dropping after users hit daily usage limits.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The dashboard | 数据看板 |
| shows | 显示 |
| engagement | 参与度 |
| dropping | 下降 |
| after | 在……之后 |
| users hit | 用户撞上 |
| daily usage limits | 每日用量限额 |

**语法拆解**
- 句型：主谓宾 + after 时间从句；宾补 dropping
- 主干：The dashboard + shows + engagement dropping
- 时态 / 语态：一般现在时
- 其他成分：show + 宾语 + -ing；呼应已学 dashboard / daily usage limits

### 句子 3
> Delivering timely alerts can raise engagement without feeling like a trap.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Delivering | 推送 / 交付 |
| timely alerts | 及时告警 |
| can raise | 可以提升 |
| engagement | 参与度 |
| without | 而不 |
| feeling like | 感觉像 |
| a trap | 一个圈套 |

**语法拆解**
- 句型：动名词主语 + 情态动词 + 动词 + 宾语 + without 短语
- 主干：Delivering timely alerts + can raise + engagement
- 时态 / 语态：一般现在时（can 表可能）
- 其他成分：呼应已学 delivering / alert / trap
