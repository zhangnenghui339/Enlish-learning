# workflow utility

- **音标**：/ˈwɜːrkfləʊ juːˈtɪləti/
- **词性**：n. phrase
- **首次日期**：2026-08-03
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：**workflow**（work + flow，工作流）+ **utility**（← 拉丁 *utilis* 有用的 → 实用工具）
- 构词提示：嵌进日常流程里的「小而专」工具，不是整套大系统；相关见 `workflow.md`、`utility.md`、`ai-workflow-utility-platform.md`

## 2. 高频常用意思

1. **工作流实用工具**（n.）— a small tool that plugs into a daily work process
2. **流程辅助工具**（n.）— helper for one step (compress, check resume, clean prompt, etc.)

## 3. 常用短语

## 4. 常用句子

### 句子 1
> Compress is a simple workflow utility for everyday files.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Compress | （工具名）压缩工具 |
| is | 是 |
| a simple | 一个简单的 |
| workflow utility | 工作流实用工具 |
| for | 用于 |
| everyday files | 日常文件 |

**语法拆解**
- 句型：主系表 + for 用途状语
- 主干：Compress + is + a workflow utility
- 时态 / 语态：一般现在时
- 其他成分：simple 修饰；for… 说明用途

### 句子 2
> They built a catalog of workflow utilities instead of one mega app.

**逐词翻译**

| 词 | 意思 |
|----|------|
| They | 他们 |
| built | 搭建了 |
| a catalog of | 一份……目录/合集 |
| workflow utilities | 工作流实用工具（复数） |
| instead of | 而不是 |
| one mega app | 一个巨型应用 |

**语法拆解**
- 句型：主谓宾 + instead of 对比
- 主干：They + built + a catalog
- 时态 / 语态：一般过去时
- 其他成分：of workflow utilities 限定目录内容；instead of… 对比产品形态
