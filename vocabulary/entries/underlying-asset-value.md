# underlying asset value

- **音标**：/ˌʌndəˈlaɪɪŋ ˈæset ˈvæljuː/（BrE）；/ˌʌndərˈlaɪɪŋ ˈæset ˈvæljuː/（AmE）
- **词性**：n. phrase（金融）
- **首次日期**：2026-08-13
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **标的资产价值**（n.）— what the company’s assets are worth underneath the stock price
2. **底层资产价值**（n.，价值投资）— cash, land, inventory, investments, etc., often close to NAV / asset value

## 2. 词根

- 词根 / 词缀：**under-**（在……之下）+ **lie**（位于）→ **underlying**（底层的、标的的）+ **asset**（资产）+ **value**（价值）
- 构词提示：underlying = 浮在表面价格下面的那一层。期权里 underlying 是「标的」；公司估值里是「公司底下那些资产本身值多少」

## 3. 常用短语

| 短语 | 音标 | 意思 |
|------|------|------|
| underlying asset | /ˌʌndəˈlaɪɪŋ ˈæset/ | 标的资产；底层资产 |
| underlying asset value | /ˌʌndəˈlaɪɪŋ ˈæset ˈvæljuː/ | 标的 / 底层资产价值 |
| net asset value (NAV) | /net ˈæset ˈvæljuː/ | 净资产价值（近义） |
| trade below asset value | /treɪd bɪˈləʊ ˈæset ˈvæljuː/ | 以低于资产价值的价格交易 |

## 4. 常用句子

### 句子 1
> The stock is cheap if the price is below the underlying asset value.
>
> /ðə stɒk ɪz tʃiːp ɪf ðə praɪs ɪz bɪˈləʊ ði ˌʌndəˈlaɪɪŋ ˈæset ˈvæljuː/

**逐词翻译**

| 词 | 音标 | 意思 |
|----|------|------|
| The stock | /ðə stɒk/ | 这只股票 |
| is cheap | /ɪz tʃiːp/ | 便宜 |
| if | /ɪf/ | 如果 |
| the price | /ðə praɪs/ | 价格 |
| is below | /ɪz bɪˈləʊ/ | 低于 |
| the underlying asset value | /ði ˌʌndəˈlaɪɪŋ ˈæset ˈvæljuː/ | 标的资产价值 |

**语法拆解**
- 句型：主句 + if 条件从句
- 主干：The stock + is + cheap
- 时态 / 语态：一般现在时
- 其他成分：below… 引出比较基准

> Holding companies often trade at a discount to underlying asset value.
>
> /ˈhəʊldɪŋ ˈkʌmpəniz ˈɒfn treɪd æt ə ˈdɪskaʊnt tə ˌʌndəˈlaɪɪŋ ˈæset ˈvæljuː/

**逐词翻译**

| 词 | 音标 | 意思 |
|----|------|------|
| Holding companies | /ˈhəʊldɪŋ ˈkʌmpəniz/ | 控股公司 |
| often | /ˈɒfn/ | 常常 |
| trade | /treɪd/ | 交易 / 定价 |
| at a discount to | /æt ə ˈdɪskaʊnt tə/ | 相对……打了折 |
| underlying asset value | /ˌʌndəˈlaɪɪŋ ˈæset ˈvæljuː/ | 底层资产价值 |

**语法拆解**
- 句型：主语 + 谓语 + 方式状语
- 主干：Holding companies + trade
- 时态 / 语态：一般现在时
- 其他成分：at a discount to… 表示相对资产价值的折价
