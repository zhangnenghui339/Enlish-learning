# brand new day

- **音标**：/ˌbrænd njuː ˈdeɪ/
- **词性**：n. phrase
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：brand-new（崭新的）+ day（一天）
- 构词提示：字面“全新的一天” → 引申为**新的开始、翻篇重来**  
  文化：漫威有故事线 / 影片企划名 **Spider-Man: Brand New Day**（蜘蛛侠：崭新之日）

## 2. 高频常用意思

1. **崭新的一天；新的开始**（n. phrase）— a fresh start; a chance to begin again
2. **（作品名）Brand New Day**（proper）— Spider-Man comic era / film title meaning a reset for the character

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| a brand new day | 崭新的一天；新开始 |
| It's a brand new day. | 新的一天开始了（可表振作） |
| Spider-Man: Brand New Day | 《蜘蛛侠：崭新之日》 |
| start a brand new day | 开启全新一天 / 重新开始 |

## 4. 常用句子

### 句子 1
> Forget yesterday — today is a brand new day.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Forget | 忘掉 |
| yesterday | 昨天 |
| today | 今天 |
| is | 是 |
| a | 一个 |
| brand new day | 崭新的一天 |

**语法拆解**
- 句型：祈使句 + 主系表（破折号连接）
- 主干：today + is + a brand new day
- 时态 / 语态：一般现在时
- 其他成分：Forget yesterday 表劝勉翻篇

### 句子 2
> Spider-Man: Brand New Day marks a fresh chapter for the hero.

**逐词翻译**

| 词 | 意思 |

| for | 对于 |

**语法拆解**

- 时态 / 语态：一般现在时
