# RSU

- **音标**：/ˌɑːr es ˈjuː/
- **词性**：n. (abbr.)
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：缩写 = **R**estricted **S**tock **U**nit（限制性股票单位）
- 构词提示：公司按归属计划给你的股票份额；通常有 **vesting**（归属期），不是入职当天就能全卖

## 2. 高频常用意思

1. **限制性股票单位**（n.）— company shares granted over time as compensation
2. **（科技 offer）股权薪酬的一部分**（n.）— often compared with salary, bonus, and tax

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| RSU grant | RSU 授予额度 |
| RSU vesting | RSU 归属 |
| vest over 4 years | 四年归属 |
| RSU refresh | RSU 追加授予 |

## 4. 常用句子

### 句子 1
> The offer has a strong RSU package that vests over four years.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The offer | 这份 offer |
| has | 有 |
| a strong | 很强的 |
| RSU package | RSU 方案 |
| that | 引导定语从句 |
| vests | 归属 |
| over four years | 历经四年 |

**语法拆解**
- 句型：主谓宾 + 定语从句
- 主干：The offer + has + a strong RSU package
- 时态 / 语态：一般现在时
- 其他成分：that vests… 说明归属节奏
