# salary

- **音标**：/ˈsæləri/
- **词性**：n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁 *salarium*（盐钱）← *sal*（盐）；古罗马曾用盐作报酬
- 构词提示：固定工资（按年/月）；对比 **wage**（常偏计时/计件工钱）

## 2. 高频常用意思

1. **薪资；薪水**（n.）— fixed pay for a job, usually monthly or yearly
2. **（招聘语境）薪资水平**（n.）— salary range / base salary

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| base salary | 基本工资 |
| salary range | 薪资范围 |
| annual salary | 年薪 |
| salary expectation | 期望薪资 |
| negotiate salary | 谈薪 |

## 4. 常用句子

### 句子 1
> What's the salary range for this role?

**逐词翻译**

| 词 | 意思 |
|----|------|
| What's | 什么是 |
| the salary range | 薪资范围 |
| for | 对于 |
| this role | 这个岗位 |

**语法拆解**
- 句型：特殊疑问句
- 主干：What is + the salary range
- 时态 / 语态：一般现在时
- 其他成分：for this role 限定岗位

### 句子 2
> They offered a higher salary plus remote benefits.

**逐词翻译**

| 词 | 意思 |
|----|------|
| They | 他们 |
| offered | 提供了 |
| a higher salary | 更高的薪水 |
| plus | 加上 |
| remote benefits | 远程相关福利 |

**语法拆解**
- 句型：主谓宾
- 主干：They + offered + a higher salary
- 时态 / 语态：一般过去时
- 其他成分：plus… 表附加
