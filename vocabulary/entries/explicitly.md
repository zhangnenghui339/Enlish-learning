# explicitly

- **音标**：/ɪkˈsplɪsɪtli/
- **词性**：adv.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：ex-（出来）+ plic（折叠）→ explicit（展开说清楚的）+ -ly
- 构词提示：explicit = 明白说出的；explicitly = 明确地、毫不含糊地  
  反义：implicitly（含蓄地、暗示地）

## 2. 高频常用意思

1. **明确地；清楚地**（adv.）— in a clear and direct way
2. **（引用/声明时）明示**（adv.）— used when quoting a clear statement

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| explicitly states | 明确指出 / 明确写道 |
| explicitly say that... | 明确说…… |
| mention explicitly | 明确提及 |
| not explicitly stated | 没有明确说明 |

## 4. 常用句子

### 句子 1
> PageCrawl.io explicitly states that no platform gives a unified view.

**逐词翻译**

| 词 | 意思 |
|----|------|
| PageCrawl.io | （来源站点） |
| explicitly | 明确地 |
| states | 陈述 / 写道 |
| that | 引导宾语从句 |
| no platform | 没有平台 |
| gives | 提供 |
| a unified view | 统一视图 |

**语法拆解**
- 句型：主语 + 状语 + 谓语 + that 从句
- 主干：PageCrawl.io + states + that...
- 时态 / 语态：一般现在时
- 其他成分：explicitly 强调“原文就写得很直白”
