# 句子解析

## 双语对照（默认，必给）

Enterprise Price < Underlying Asset Value
企业价格 < 标的资产价值（买下整家公司的价格，低于公司底下那些资产本身值多少钱）。

## 补充

| 表达 | 音标 | 意思 |

| Underlying Asset Value | /ˌʌndəˈlaɪɪŋ ˈæset ˈvæljuː/ | 标的 / 底层资产价值 |

### 语法拆解
1. **句型**：不等式 / 筛选条件（不是完整主谓句）
2. **主干**：Enterprise Price + is less than + Underlying Asset Value
3. **时态 / 语态**：无动词；投资里常当一条选股规则来读
4. **修饰成分**：左侧是「你付多少」，右侧是「资产值多少」
5. **难点**：Price ≠ Value。左边是买价，右边是资产估值；左边更小，表示可能买便宜了
