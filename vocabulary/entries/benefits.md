# benefits

- **音标**：/ˈbenɪfɪts/
- **词性**：n. (usually plural in HR)
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁 *bene*（好）+ *facere*（做）→ benefit（好处）→ benefits（复数：福利待遇）
- 构词提示：招聘里 **benefits** ≈ 医保、年假、期权等薪资外待遇；单数 benefit 也可作“益处 / 受益”

## 2. 高频常用意思

1. **（员工）福利**（n. pl.）— extras from an employer beyond salary
2. **好处；益处**（n.）— an advantage；the benefits of remote work
3. **受益**（v. benefit）— to gain an advantage

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| employee benefits | 员工福利 |
| health benefits | 医疗福利 |
| benefits package | 福利包 |
| salary and benefits | 薪资与福利 |
| full benefits | 全套福利 |

## 4. 常用句子

### 句子 1
> The salary is average, but the benefits are excellent.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The salary | 薪水 |
| is | 是 |
| average | 一般的 |
| but | 但是 |
| the benefits | 福利 |
| are | 是 |
| excellent | 非常好的 |

**语法拆解**
- 句型：并列转折句
- 主干：The salary is average / the benefits are excellent
- 时态 / 语态：一般现在时
- 其他成分：but 连接对比

### 句子 2
> Does the offer include health benefits?

**逐词翻译**

| 词 | 意思 |
|----|------|
| Does | 助动词 |
| the offer | 这份录用条件 |
| include | 包含 |
| health benefits | 医疗福利 |

**语法拆解**
- 句型：一般疑问句
- 主干：Does + the offer + include + health benefits
- 时态 / 语态：一般现在时
- 其他成分：求职谈 offer 高频问法
