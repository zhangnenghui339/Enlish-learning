# cognitive

- **音标**：/ˈkɑːɡnətɪv/（美）/ˈkɒɡnətɪv/（英）
- **词性**：adj.
- **首次日期**：2026-09-14
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **认知的**（adj.）
   - 中文：跟大脑怎么获取、处理、记住信息有关的
   - 英文解释：relating to the mind’s work of knowing — perceiving, remembering, reasoning, and making sense of information
2. **思维 / 智力方面的**（adj.）
   - 中文：偏「脑子怎么转」，不是情绪、也不是身体动作
   - 英文解释：about mental processing rather than feelings or physical action; used when you contrast thinking with emotion or motor skill

## 2. 原子意思

- **原子**：拉丁 *cognoscere* = **彻底搞清楚、认得上来**（*com-* 彻底 + *gnoscere* 知道）
- **英文取词**：描述脑子**动起来**什么样 —— 在「知道」：接收、识别、加工、想通
- **中文取词**：描述看起来在谈哪一类能力 —— 谈获取信息叫**认知**，谈脑子怎么转叫**思维**，谈聪明程度叫**智力**
- **所以不是一词多义**：同一个「脑子在知道」；中文才按场合拆成不同词

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **cognitive ability** | 脑子「能知道、能加工」的那套本事 | 看起来是能力名 → **认知能力** |
| **cognitive decline** | 「知道」这套机器变慢、变钝 | 看起来是老化/病 → **认知衰退** |
| **cognitive bias** | 知道的过程被系统性拧歪了 | 看起来是判断偏差 → **认知偏差** |
| **cognitive vs emotional** | 一边是知道/想，一边是感觉 | 中文改口说**思维层面**，对照**情绪层面** |

名词 **cognition** = 那套「知道」的过程本身 → 中文叫**认知**。

## 3. 词根

- 词根 / 词缀：**co(g)-**（彻底、一起）+ **gnos- / gnit-** ← 拉丁 *gnoscere / noscere*（知道）+ **-ive**（……的）
- 真同源：
  - **cognition** — 认知（知道的过程）
  - **cognizant** — 意识到的、知情的
  - **recognize / recognition** — 再一次认得上来 → 认出；承认
  - **incognito** — 不被知道 → 隐姓埋名
  - **ignore / ignorant** — 不去知道 / 不知道
  - **agnostic** — 声称「不可知」
  - **notice / notable** — 注意到；值得被知道
  - **know / knowledge** — 日耳曼语亲戚（同一印欧词根 *gno-*「知道」）
- 形近勿混：
  - **cognate** — 「同族词；同源的」，来自拉丁 *cognatus*（一起出生），词根是 *nat-*（生），**不是**「知道」
  - **cognac** — 干邑白兰地，法国地名，跟「认知」无关
- 构词提示：看见 **cogn- / gnos- / gnit-** 先问「是不是在知道、认得」；看见 **cognate** 先问「是不是一起出生、同源」，别和 cognitive 捆成一家

## 5. 常用句子

### 句子 1
> Cognitive skills include memory, attention, and problem-solving.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Cognitive skills | 认知技能 |
| include | 包括 |
| memory | 记忆 |
| attention | 注意力 |
| and | 和 |
| problem-solving | 解决问题 |

**语法拆解**
- 句型：主谓 + 宾语（并列三项）
- 主干：Cognitive skills + include + memory, attention, and problem-solving
- 时态 / 语态：一般现在时（定义/事实）
- 其他成分：Cognitive 作 skills 的前置定语，标出是「知道/加工」那一类技能

### 句子 2
> Sleep loss increases cognitive load and slows thinking.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Sleep loss | 睡眠不足 |
| increases | 增加 |
| cognitive load | 认知负荷 |
| and | 并且 |
| slows | 减慢 |
| thinking | 思考 |

**语法拆解**
- 句型：主语 + 并列谓语
- 主干：Sleep loss + increases… and slows…
- 时态 / 语态：一般现在时
- 其他成分：cognitive load = 脑子正在「知道」时堆了多少活；and 连接两个结果

### 句子 3
> The study measured cognitive decline in older adults.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The study | 这项研究 |
| measured | 测量了 |
| cognitive decline | 认知衰退 |
| in older adults | 在老年人当中 |

**语法拆解**
- 句型：主谓宾 + 地点/对象状语
- 主干：The study + measured + cognitive decline
- 时态 / 语态：一般过去时
- 其他成分：in older adults 标出在谁身上测；decline 是「知道这套能力往下掉」
