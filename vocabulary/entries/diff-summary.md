# Diff Summary

- **音标**：/dɪf ˈsʌməri/
- **词性**：n. phrase（产品功能名）
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **差异摘要 / 改动总结**（n.）— a short overview of what changed in a diff or pull request
2. **diff** — 差异对比（文件/代码改动的对比结果）
3. **summary** — 摘要；总结

## 2. 词根

- 词根 / 词缀：
  - **diff** ← **difference** 的缩写（差异）
  - **summary** ← 拉丁 *summarium*（概要）
- 构词提示：把 **diff（代码差异）** 压成 **summary（摘要）** → 常见于 GitHub PR 场景

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| Diff Summary | 差异摘要；改动总结 |
| pull request (PR) | 拉取请求；合并请求 |
| code diff | 代码差异 |
| summarize changes | 总结改动 |

## 4. 常用句子

### 句子 1
> The Diff Summary explains what this PR changes.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The Diff Summary | 差异摘要 |
| explains | 解释 |
| what this PR changes | 这个 PR 改了什么 |

**语法拆解**
- 句型：主谓宾（what 引导的名词性从句作宾语）
- 主干：Diff Summary + explains + what …
- 时态 / 语态：一般现在时
- 其他成分：what this PR changes 是宾语从句

### 句子 2
> I paste the GitHub PR into Diff Summary before review.

**逐词翻译**

| 词 | 意思 |
|----|------|
| I | 我 |
| paste | 粘贴 |
| the GitHub PR | GitHub 上的 PR |
| into Diff Summary | 到差异摘要工具里 |
| before review | 在评审之前 |

**语法拆解**
- 句型：主谓宾 + into + 时间状语
- 主干：I + paste + PR + into + Diff Summary
- 时态 / 语态：一般现在时
- 其他成分：before review 表时间
