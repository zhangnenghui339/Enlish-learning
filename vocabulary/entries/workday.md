# Workday

- **音标**：/ˈwɜːrkdeɪ/
- **词性**：n. (proper) / 普通义 n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：work + day；作产品名时整体指 **Workday**（企业 HR / 财务云平台）
- 构词提示：求职里看到 “Apply with Workday” = 用这套企业系统投递；普通英文 *workday* 也可指工作日

## 2. 高频常用意思

1. **Workday（产品）**（proper n.）— enterprise HR / recruiting / finance software used by large companies
2. **工作日**（n.）— a day on which people work；on a workday

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| apply via Workday | 通过 Workday 投递 |
| Workday ATS / career site | Workday 招聘系统 / 招聘站 |
| Workday account | Workday 账号（大公司常要重复注册） |

## 4. 常用句子

### 句子 1
> Many large companies use Workday for hiring.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Many large companies | 许多大公司 |
| use | 使用 |
| Workday | Workday |
| for hiring | 用于招聘 |

**语法拆解**
- 句型：主谓宾 + 目的状语
- 主干：companies + use + Workday
- 时态 / 语态：一般现在时
- 其他成分：for hiring 表用途
