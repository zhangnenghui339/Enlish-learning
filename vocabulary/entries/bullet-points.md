# bullet points

- **音标**：/ˈbʊlɪt pɔɪnts/
- **词性**：n. phrase（常用复数）
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：
  - **bullet** ← 法语 *boulette*（小球）→ 子弹/弹头；印刷里指小圆点「•」
  - **point** ← 拉丁 *punctum*（点）→ 要点；论点
- 构词提示：**bullet**（圆点符号）+ **points**（要点）→ 用「•」列出的要点清单

## 2. 高频常用意思

1. **要点列表**（n.）— short items marked with • in a list; 条目式摘要
2. **提纲/要点**（n.）— key takeaways written as short lines（会议、幻灯片、邮件常用）
3. **bullet point**（单数）— 列表中的一条；也可指那个圆点符号本身

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| bullet points | 要点列表；条目式要点 |
| in bullet points | 用要点形式（列出） |
| add / write bullet points | 添加 / 写出要点 |
| key bullet points | 关键要点 |
| bullet-point list | 条目列表 |
| reduce to bullet points | 压缩成要点 |

## 4. 常用句子

### 句子 1
> Please summarize the report in bullet points.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Please | 请 |
| summarize | 总结 |
| the report | 这份报告 |
| in | 以……方式 |
| bullet points | 要点列表 |

**语法拆解**
- 句型：祈使句 + 方式状语
- 主干：（you）+ summarize + the report
- 时态 / 语态：祈使语气（一般现在）
- 其他成分：in bullet points 表呈现形式

### 句子 2
> Her slides use clear bullet points instead of long paragraphs.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Her slides | 她的幻灯片 |
| use | 使用 |
| clear | 清晰的 |
| bullet points | 要点条目 |
| instead of | 而不是 |
| long paragraphs | 长段落 |

**语法拆解**
- 句型：主谓宾 + instead of 对比
- 主干：Her slides + use + bullet points
- 时态 / 语态：一般现在时
- 其他成分：clear 修饰 bullet points；instead of… 对比写法
