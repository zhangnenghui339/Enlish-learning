# AI PDF Summarizer

- **音标**：/ˌeɪˈaɪ ˌpiːdiːˈef ˈsʌməraɪzər/
- **词性**：n. phrase（产品/工具名）
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：
  - **AI** = Artificial Intelligence（人工智能）的缩写
  - **PDF** = Portable Document Format（便携式文档格式）
  - **summarizer** = **summarize**（总结）+ **-er**（做……的人/物）→ 做摘要的工具
- 构词提示：用 AI 把 PDF **自动压成摘要**的工具名；见词就能猜功能

## 2. 高频常用意思

1. **AI PDF 摘要器**（n.）— a tool that uses AI to summarize PDF documents
2. **summarizer**（单独）— 摘要工具；做总结的人/程序
3. **summarize**（相关动词）— 总结；概括要点

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| AI PDF Summarizer | AI PDF 摘要工具 |
| summarize a PDF | 总结一份 PDF |
| PDF summary | PDF 摘要 |
| upload a PDF | 上传 PDF |
| one-click summary | 一键摘要 |
| extract key points | 提取关键要点 |

## 4. 常用句子

### 句子 1
> The AI PDF Summarizer turns a long report into bullet points.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The AI PDF Summarizer | 这款 AI PDF 摘要工具 |
| turns | 把……变成 |
| a long report | 一份很长的报告 |
| into | 变成 |
| bullet points | 要点列表 |

**语法拆解**
- 句型：主谓宾 + into 补语（turn A into B）
- 主干：The AI PDF Summarizer + turns + a long report
- 时态 / 语态：一般现在时（表功能）
- 其他成分：into bullet points 说明结果形态

### 句子 2
> I use an AI PDF summarizer before every client meeting.

**逐词翻译**

| 词 | 意思 |
|----|------|
| I | 我 |
| use | 使用 |
| an AI PDF summarizer | 一款 AI PDF 摘要工具 |
| before | 在……之前 |
| every client meeting | 每次客户会议 |

**语法拆解**
- 句型：主谓宾 + 时间状语
- 主干：I + use + an AI PDF summarizer
- 时态 / 语态：一般现在时（习惯）
- 其他成分：before every client meeting 表使用场景
