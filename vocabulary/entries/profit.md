# profit

- **音标**：/ˈprɒfɪt/（BrE）; /ˈprɑːfɪt/（AmE）
- **词性**：n. / v.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：拉丁语 proficere（前进、获益）→ pro-（向前）+ ficere / facere（做）
- 构词提示：真正“获益”的部分 = 收入 − 成本；易混拼写/读音：**profile**（个人资料/侧面），词源不同

## 2. 高频常用意思

1. **利润**（n.）— money left after costs are subtracted from revenue
2. **获利；受益**（v.）— to gain money or benefit from something

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| make a profit | 获利；赚钱 |
| gross profit | 毛利 |
| net profit | 净利润 |
| profit margin | 利润率 |
| profitable（adj.） | 有盈利的 |
| profit from... | 从……中获利 |

## 4. 常用句子

### 句子 1
> The startup finally made a profit this year.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The startup | 这家初创公司 |
| finally | 终于 |
| made | 获得了 |
| a | 一笔 |
| profit | 利润 |
| this year | 今年 |

**语法拆解**
- 句型：主谓宾 + 时间状语
- 主干：The startup + made + a profit
- 时态 / 语态：一般过去时
- 其他成分：finally 表语气；this year 表时间

### 句子 2
> Revenue was high, but profit remained low.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Revenue | 营收 |
| was | 是 |
| high | 高的 |
| but | 但是 |
| profit | 利润 |
| remained | 仍然是 |
| low | 低的 |

**语法拆解**
- 句型：并列句（转折）
- 主干：Revenue was high / profit remained low
- 时态 / 语态：一般过去时
- 其他成分：but 连接对比
