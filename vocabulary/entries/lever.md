# Lever

- **音标**：/ˈlevər/（AmE）; /ˈliːvər/（BrE，工具义时常）
- **词性**：n. (proper) / 普通义 n.
- **首次日期**：2026-07-31
- **来源**：chat
- **掌握**：new

## 1. 词根

- 词根 / 词缀：普通义 lever = 杠杆；产品名 **Lever** = ATS / 招聘平台
- 构词提示：求职里和 Greenhouse、Ashby 同类；也常出现在 “Apply with Lever”

## 2. 高频常用意思

1. **Lever（产品）**（proper n.）— an ATS / recruiting software platform
2. **杠杆；操纵杆**（n.）— a bar used to move something；a means of influence

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| apply with Lever | 通过 Lever 申请 |
| Lever ATS | Lever 招聘系统 |
| Greenhouse and Lever | 两大常见 ATS 品牌（常被对比） |

## 4. 常用句子

### 句子 1
> Startups often use Greenhouse, Ashby, or Lever.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Startups | 创业公司 |
| often | 经常 |
| use | 使用 |
| Greenhouse, Ashby, or Lever | Greenhouse、Ashby 或 Lever |

**语法拆解**
- 句型：主谓宾
- 主干：Startups + use + Greenhouse / Ashby / Lever
- 时态 / 语态：一般现在时
- 其他成分：or 连接并列选项
