# preferences

- **音标**：/ˈprefərənsɪz/
- **词性**：n.（常用复数；单数 preference）
- **首次日期**：2026-08-26
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **偏好；更喜欢的东西**（n.）
   - 中文：你比起别的选项，更往前放、更想要的那一类
   - 英文解释：the things you like more than the alternatives; what you would choose if you got to put one option first
2. **（软件）偏好设置**（n. pl.）
   - 中文：App / 系统里让你把「我更想怎样」存下来的那一页设置
   - 英文解释：a settings screen where you store how you want the software to behave — dark mode, language, notifications, etc.
3. **优先（权）**（n.）
   - 中文：正式场合里把某人或某事排在别人前面
   - 英文解释：the act of ranking one person or option ahead of others (give preference to local candidates)

## 2. 原子意思

- **原子**：拉丁 *praeferre* = *prae-*（在前）+ *ferre*（拿、带）→ **把某一项拿到别人前面**
- **英文取词**：描述动作 —— 在一排选项里，把其中一个**往前拎**
- **中文取词**：描述看起来在处理哪一类对象 —— 口味叫**偏好**，软件叫**偏好设置**，排队叫**优先**
- **所以不是一词多义**：同一个「拿到前面」；中文才按对象拆成不同词

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **food preferences** | 把某些味道拿到别的前面 | 看起来是「口味」→ **偏好** |
| **user preferences** | 把你想要的用法存成默认、排在前面 | 看起来是「设置页」→ **偏好设置** |
| **give preference to** | 把某人/某事排到队列前面 | 看起来是「插队权」→ **优先** |
| **prefer tea to coffee** | 动词：把茶拿到咖啡前面 | 中文改口说**更喜欢** |

单数 **preference** 是「那一次往前拎」；复数 **preferences** 常指一整套被拎到前面的选项（口味清单，或软件里那一页）。

## 3. 词根

- 词根 / 词缀：**pre-**（在前）+ **fer**（拿、带 ← 拉丁 *ferre*）+ **-ence**（名词）
- 真同源：
  - **prefer / preferable / preferably** — 更喜欢；更可取
  - **preferential** — 优惠的；优先的（preferential treatment 优待）
  - **refer / reference** — 拿回去对照（*re-* 回）
  - **transfer** — 拿过去（*trans-* 越过）
  - **confer** — 拿到一起商量（*con-* 一起）
  - **differ** — 拿到不同方向 → 不同（*dis-* 分开）
- 形近勿混：
  - **performance** — 来自 *perform*（做完、演），不是「拿到前面」
  - **presence** — 来自 *present*（在场），不是 prefer
  - **prefect** — 长官，另一条词源
- 构词提示：看见 **pre- + fer** 先问「是不是把某样东西拿到前面」；同一家 *ferre* 的亲戚很多，前缀不同，方向就不同

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| food / music preferences | 饮食 / 音乐偏好 |
| personal preferences | 个人偏好 |
| user preferences | 用户偏好设置 |
| System Preferences | （macOS）系统偏好设置 |
| a matter of preference | 个人喜好问题 |
| in order of preference | 按偏好顺序 |
| give preference to | 优先考虑 / 给予优先 |
| have a preference for | 更偏向于 |

## 5. 常用句子

### 句子 1
> Do you have any food preferences?

**逐词翻译**

| 词 | 意思 |
|----|------|
| Do you have | 你有没有 |
| any | 任何 |
| food preferences | 饮食偏好 |

**语法拆解**
- 句型：一般疑问句
- 主干：you + have + preferences
- 时态 / 语态：一般现在时
- 其他成分：food 作定语，标出「拿到前面」的是吃的

### 句子 2
> You can change the language in Preferences.

**逐词翻译**

| 词 | 意思 |
|----|------|
| You | 你 |
| can change | 可以改 |
| the language | 语言 |
| in Preferences | 在偏好设置里 |

**语法拆解**
- 句型：情态动词 + 主谓宾 + 地点状语
- 主干：You + can change + the language
- 时态 / 语态：现在时（能力 / 许可）
- 其他成分：in Preferences 表位置；这里 Preferences 当软件菜单名，常大写

### 句子 3
> The company gives preference to candidates with remote experience.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The company | 这家公司 |
| gives preference to | 优先考虑 |
| candidates | 候选人 |
| with remote experience | 有远程工作经验的 |

**语法拆解**
- 句型：主谓宾 + 介词短语
- 主干：The company + gives + preference
- 时态 / 语态：一般现在时（公司政策）
- 其他成分：to candidates 间接对象；with… 后置定语
