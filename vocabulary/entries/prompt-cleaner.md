# Prompt Cleaner

- **音标**：/prɒmpt ˈkliːnə/
- **词性**：n. phrase（产品功能名）
- **首次日期**：2026-08-01
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **提示词清理器**（n.）— a tool that tidies, shortens, or fixes a prompt before sending it to an AI
2. **prompt** — 提示词；给 AI 的指令文本
3. **cleaner** — 清理器；整理工具

## 2. 词根

- 词根 / 词缀：
  - **prompt** ← 「提示；催促」→ AI 语境里指输入指令
  - **cleaner** = **clean** + **-er**
- 构词提示：把杂乱 **prompt** 变干净再丢给 ChatGPT 等模型

## 3. 常用短语

| 短语 | 意思 |
|------|------|
| Prompt Cleaner | 提示词清理器 |
| clean up a prompt | 清理/整理提示词 |
| prompt engineering | 提示词工程 |
| rewrite the prompt | 改写提示词 |

## 4. 常用句子

### 句子 1
> Use Prompt Cleaner before pasting into ChatGPT.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Use | 使用 |
| Prompt Cleaner | 提示词清理器 |
| before pasting | 在粘贴之前 |
| into ChatGPT | 到 ChatGPT 里 |

**语法拆解**
- 句型：祈使句 + before + 动名词
- 主干：(You) + use + Prompt Cleaner
- 时态 / 语态：一般现在时（祈使）
- 其他成分：before pasting into ChatGPT 作时间状语

### 句子 2
> The Prompt Cleaner removes fluff and keeps the key instructions.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The Prompt Cleaner | 提示词清理器 |
| removes | 去掉 |
| fluff | 废话；注水内容 |
| and | 并且 |
| keeps | 保留 |
| the key instructions | 关键指令 |

**语法拆解**
- 句型：主谓宾 + and + 并列谓语
- 主干：Prompt Cleaner + removes + fluff；keeps + instructions
- 时态 / 语态：一般现在时
- 其他成分：key 作定语修饰 instructions
