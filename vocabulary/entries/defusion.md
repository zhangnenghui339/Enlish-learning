# defusion

- **音标**：/ˌdiːˈfjuːʒn/（亦作 /dɪˈfjuːʒən/）
- **词性**：n.
- **首次日期**：2026-09-14
- **来源**：chat
- **掌握**：new
- **相关条目**：[`cognitive.md`](cognitive.md)（常说 cognitive defusion）

## 1. 高频常用意思

1. **（认知）解离；去融合**（n.，心理 / ACT）
   - 中文：把「我」和脑子里那句话拆开，看着它，而不是变成它
   - 英文解释：in Acceptance and Commitment Therapy, stepping back from a thought so it is just a thought — words passing by — not a fact you have to obey or a self you have to be
2. **与想法脱钩**（n.）
   - 中文：不跟念头较劲、也不吞下去，让它在那儿，人还能做事
   - 英文解释：unhooking from mental content: you notice the thought, loosen its grip, and keep moving with your values instead of arguing with it or fusing with it

（日常英语里「拆炸弹引信 / 缓和气氛」的动词是 **defuse**，名词多用 *defusing*，一般不写成 defusion。）

## 2. 原子意思

- **原子**：拉丁 *fundere* = **倒、熔**；*fusion* = 熔在一起；**de-fusion** = **把熔在一起的东西拆开**
- **英文取词**：描述动作 —— 念头曾经和「我」熔成一块；现在把这块**揭开、松开**
- **中文取词**：谈 ACT 技术叫**认知解离 / 去融合**；谈体验叫**和想法脱钩**；千万别写成**扩散**（那是 diffusion）
- **所以不是一词多义**：同一个「从熔住的状态里退出来」；中文才按课堂术语和日常说法拆开

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **cognitive fusion** | 念头和自我熔成一块：「我没人爱」= 我这个人 | **认知融合** |
| **cognitive defusion** | 把熔住的那块揭开：这只是一句飘过的话 | **认知解离 / 去融合** |
| **defuse a bomb / a fight** | 另一条路：把引信拿掉，让爆炸停住 | 动词 **拆除引信 / 缓和**；一般不说 defusion |
| **diffusion** | 同一「倒」家族，但是**倒开、散开** | **扩散**（拼写多一个 i，意思完全不同） |

练习画面：在念头前加上 *I'm having the thought that…* —— 人站回观察位，话不再焊在身上。

## 3. 词根

- 词根 / 词缀：**de-**（去掉、反向）+ **fus-** ← 拉丁 *fundere / fusus*（倒、熔）+ **-ion**（行为 / 状态）
- 真同源：
  - **fusion** — 融合；熔接
  - **fuse**（动词）— 熔在一起
  - **confuse / confusion** — 倒在一起分不清 → 混淆
  - **infuse** — 倒进去 → 注入
  - **refund** — 倒回去 → 退款
  - **foundry** — 熔铸的地方
- 形近勿混：
  - **diffusion** — *dis-*（分开）+ *fundere* → 倒开、散开 → **扩散**；多一个 **i**，不是解离
  - **defuse** — *de-* + **fuse**（引信）→ 拆炸弹；引申为缓和紧张。同源远亲，但英语里当另一个词用
  - **delusion** — 妄想，来自 *ludere*（玩、骗），**不是** fusion 一家
- 构词提示：看见 **defusion** 先问「是不是从融合里退出来」；看见 **diffusion** 先问「是不是散开」；看见 **defuse** 先问「是不是拆引信 / 降温」

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| cognitive defusion | 认知解离（ACT 核心技术） |
| defusion technique / exercise | 解离练习 |
| practice defusion | 练习与想法脱钩 |
| fusion and defusion | 融合与解离 |
| defuse from a thought | （有人这样说）从某个念头上松开；更规范常说 *defuse a thought* 或 *use defusion with a thought* |
| I'm having the thought that… | 我正有这样一个念头……（经典解离句式） |

## 5. 常用句子

### 句子 1
> Cognitive defusion means seeing thoughts as thoughts, not as commands.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Cognitive defusion | 认知解离 |
| means | 意思是 |
| seeing | 把……看成 |
| thoughts | 念头 |
| as thoughts | 当作念头 |
| not as commands | 而不是当作命令 |

**语法拆解**
- 句型：主谓宾（means + 动名词短语）
- 主干：Cognitive defusion + means + seeing…
- 时态 / 语态：一般现在时（下定义）
- 其他成分：as thoughts / not as commands 是 seeing 的方式补足语——熔住时念头=命令，揭开后念头=念头

### 句子 2
> She used a defusion exercise: "I'm having the thought that I will fail."

**逐词翻译**

| 词 | 意思 |
|----|------|
| She | 她 |
| used | 用了 |
| a defusion exercise | 一个解离练习 |
| I'm having the thought that | 我正有这样一个念头，即…… |
| I will fail | 我会失败 |

**语法拆解**
- 句型：主谓宾 + 冒号后引用
- 主干：She + used + a defusion exercise
- 时态 / 语态：一般过去时；引语里现在进行 + will
- 其他成分：I'm having the thought that… 把失败者从「我是」改成「我正在有一句话」——熔块被揭开

### 句子 3
> Fusion tightens around worry; defusion loosens the grip.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Fusion | 融合 |
| tightens | 收紧 |
| around worry | 绕着担忧 |
| defusion | 解离 |
| loosens | 松开 |
| the grip | 那股抓力 |

**语法拆解**
- 句型：并列句（分号连接两个主谓）
- 主干：Fusion + tightens；defusion + loosens + the grip
- 时态 / 语态：一般现在时（对照两种状态）
- 其他成分：around worry 标出熔在哪；the grip 就是念头焊在身上的那股力
