# assumption

- **音标**：/əˈsʌmpʃn/（亦作 /əˈsʌmpʃən/）
- **词性**：n.
- **首次日期**：2026-09-14
- **来源**：chat
- **掌握**：new

## 1. 高频常用意思

1. **假设；假定**（n.）
   - 中文：还没证明，先当成真的那句话
   - 英文解释：something you take as true without proving it first — a belief you have already “picked up” and are standing on
2. **承担；就任**（n.）
   - 中文：把职位、责任、权力接到自己身上
   - 英文解释：the act of taking on a role, duty, or power — you lift it onto yourself
3. **（宗教）圣母升天**（n.，常大写 the Assumption）
   - 中文：天主教里圣母玛利亚被接到天上
   - 英文解释：the belief that Mary was taken up into heaven; the feast named for that “taking up”

## 2. 原子意思

- **原子**：拉丁 *assumere* = **朝自己拿过来**（*ad-* 朝向 + *sumere* 拿、取）
- **英文取词**：描述动作 —— **把某物接到自己这边**：接到脑子里当真相，接到肩上当职责，接到天上当身体
- **中文取词**：描述看起来在拿哪一类东西 —— 拿未经证明的想法叫**假设**，拿职位叫**承担**，拿圣母的身体叫**升天**
- **所以不是一词多义**：同一个「拿过来、接上身」；中文才按对象拆成不同词

分叉示例：

| 英文 | 原子怎么套 | 中文为什么另起一词 |
|------|------------|-------------------|
| **that's a big assumption** | 把未经证明的话接到脑子里当底座 | 看起来是「先当它真」→ **假设** |
| **the assumption of power** | 把权力接到自己手里 | 看起来是「接任」→ **掌握 / 承担** |
| **the Assumption of Mary** | 身体被接到天上 | 宗教专名 → **圣母升天** |
| **assume a role / assume control** | 动词：把角色、控制权套上身 | 中文改口说**扮演 / 接管**，不再用「假设」 |

动词 **assume** = 这个「拿过来」的动作本身。

## 3. 词根

- 词根 / 词缀：**as-** ← *ad-*（朝向）+ **sumpt- / sum-** ← 拉丁 *sumere*（拿、取）+ **-ion**（行为 / 结果）
- 真同源：
  - **assume** — 假定；承担；装出
  - **consume** — 彻底拿光 → 消耗；吃掉
  - **presume / presumption** — 事先拿过来 → 推测；擅自认定
  - **resume** — 再拿起来 → 恢复；简历（把经历再摊出来）
  - **sumptuous** — 花销拿得很大 → 奢华的
- 形近勿混：
  - **assurance / assure** — 来自 *securus*（稳妥），是「说稳、保证」，**不是**「拿过来」
  - **consumption** — 倒是真亲戚（消耗），别只看成「消费」一个中文词
  - **assumption** 和 **presumption**：都是「先拿来当真」；presume 更冲，常带「未经允许就认定」
- 构词提示：看见 **sume / sumpt / sump** 先问「是不是在拿、取」；**assur-** 是另一家（稳）

## 4. 常用短语

| 短语 | 意思 |
|------|------|
| make an assumption | 做一个假设 |
| based on the assumption that… | 基于……这一假定 |
| a false / underlying assumption | 错误的 / 底层的假设 |
| challenge an assumption | 质疑某个假设 |
| on the assumption that… | 假定……的前提下 |
| the assumption of power / responsibility | 掌握权力 / 承担责任 |
| the Assumption | 圣母升天（节） |

## 5. 常用句子

### 句子 1
> That's a big assumption — we haven't tested it yet.

**逐词翻译**

| 词 | 意思 |
|----|------|
| That's | 那是 |
| a big assumption | 一个很大的假设 |
| we haven't tested it yet | 我们还没有验证过它 |

**语法拆解**
- 句型：主系表 + 破折号后补充说明
- 主干：That + is + a big assumption
- 时态 / 语态：一般现在时；后半句现在完成时否定
- 其他成分：big 标出「拿过来当真」拿得太多；破折号后解释为什么大

### 句子 2
> The plan is based on the assumption that users will stay.

**逐词翻译**

| 词 | 意思 |
|----|------|
| The plan | 这个计划 |
| is based on | 建立在……之上 |
| the assumption | 这个假定 |
| that users will stay | 即用户会留下来 |

**语法拆解**
- 句型：主谓 + on 介词短语 + that 同位语从句
- 主干：The plan + is based on + the assumption
- 时态 / 语态：一般现在时；从句 will 表将来
- 其他成分：that users will stay 就是被「拿过来当底座」的那句话

### 句子 3
> Her assumption of the role surprised the team.

**逐词翻译**

| 词 | 意思 |
|----|------|
| Her assumption | 她的承担 / 接任 |
| of the role | 这个角色 |
| surprised | 使……吃惊 |
| the team | 团队 |

**语法拆解**
- 句型：主谓宾
- 主干：Her assumption of the role + surprised + the team
- 时态 / 语态：一般过去时
- 其他成分：of the role 标出「拿上身」的是职位，不是假设；这里 assumption ≠ 假设
